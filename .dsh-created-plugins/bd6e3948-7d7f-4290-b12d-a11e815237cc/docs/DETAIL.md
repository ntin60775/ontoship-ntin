# Доска цепочки OntoShip

Виджет правой панели: текущий юнит OntoShip как один ticket-DAG.

## Что показывает

- **Граф зависимостей** — тикеты юнита узлами, рёбра «блокер → зависимый»
  стрелками; слои слева направо по глубине блокировок.
- **Kanban** — пять колонок: `Blocked`, `Ready`, `В работе`, `Ждёт приёмки`,
  `Принят`. Колонка `Blocked` вычисляется из рёбер: тикет заблокирован, пока
  хотя бы один его блокер не сделан. Колонка `Ready` — вычисляемый frontier:
  все блокеры сняты, работа не начата.
- **Цвета статусов — палитра Temporal UI** (badge color schemes из
  `temporalio/ui`):

  | Статус тикета | Схема Temporal | Источник цвета |
  |---|---|---|
  | Blocked | neutral | Canceled |
  | Ready | accent | accent-схема бейджа |
  | В работе | info | Running |
  | Ждёт приёмки | warning | Terminated |
  | Принят | success | Completed |

  Светлая и тёмная темы следуют за темой хоста (`data-ds-dark-theme`).

## Данные и обновление

- Тикеты и рёбра — `tickets/<slug>/` рабочей папки сессии: файл тикета
  опознаётся маркером `**Блокируется:**`, номер и заголовок — первым
  заголовком `# NN: …`, блокеры — строкой «Блокируется» (одиночные номера,
  перечисления и диапазоны `01–07`). Отчёты-артефакты без маркера не тикеты.
- Состояние — `docs/ops/continue.md`: текущий юнит — последний открытый и не
  закрытый (`Открыт юнит …` / `юнит … закрыт`); статусы тикетов — из абзаца
  юнита в разделе «Порядок тикетов» («сделан», «принят», «ждёт приёмки»,
  «в работе»). Приёмка в нарезке («принят со сверкой понимания») статусом
  исполнения не считается. Если continue.md о тикете молчит, «сделан»
  определяется по самому тикету: все критерии `- [x]` и раздел
  «Доказательства».
- Виджет следит за `docs/ops/continue.md` и папкой `tickets/<slug>/` через
  штатный `workspaceFiles.changes` и перечитывает данные при изменениях;
  при смене юнита подписки переставляются. Ничего не хранит: все виды —
  производные от markdown + git.

## Использование

Вкладка открывается автоматически при появлении сессии на экране, если в
рабочей папке есть `docs/ops/continue.md` (один раз на сессию); также
доступна из guide-страницы правой панели («Доска цепочки»). Клик по карточке
или узлу открывает файл тикета в штатном просмотрщике файлов. Переключатель
«Граф / Kanban» меняет вид; кнопка обновления в меню вкладки перечитывает
данные.

## Ограничения

- Только чтение: плагин не изменяет файлы, не добавляет инструментов,
  операций и источников данных.
- Разбор состояния — эвристика по каноническим формулировкам runbook;
  нестандартные формулировки могут не распознаться (тикет останется в
  вычисляемой колонке по рёбрам и чекбоксам).
- Циклы в рёбрах не ожидаются (метод гарантирует DAG); при цикле узлы
  получают слой по разрешимой части, граф остаётся читаемым.
