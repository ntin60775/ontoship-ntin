# Базовые стандарты инженерии и стека

Базовый документ стандартов проекта: общие лучшие практики инженерии
и практики стека этого репозитория, собранные из знаний модели. Это
не стандарты команды и не стандарты отрасли: пак команды и пак стека,
когда появятся, перекрывают этот документ по приоритету норм. Методные
правила (фазы, гейты, качество доказательств) живут в каноне и
справочниках — этот документ их не пересказывает.

## Приоритет норм

канон > стандарты проекта > пак команды > пак стека > базовый документ.

Неразрешимый конфликт норм — вопрос оператору, молчаливый перевес
не делается. Источник стандартов называется во входе панели: документы
стандартов идут ревьюеру в порядке приоритета, базовый документ —
последним.

## Общие практики инженерии

- Читай перед записью: пойми окружающий код и документы, прежде чем
  менять; правка читается как окружение.
- Одна правка — одна цель; смешанные изменения разрезаются.
- Имена раскрывают намерение; комментарии объясняют «почему», не
  пересказывают «что».
- Ошибки названы внятно: именованный отказ с причиной, пустой stdout
  при отказе; молчаливое проглатывание и молчаливый фолбэк запрещены.
- Мёртвый код и дублирование удаляются, а не комментируются и не
  копируются.
- Детерминизм: никакой скрытой зависимости от времени, сети, порядка
  и окружения в проверках.
- Доказательство вместо утверждения: прогон выполнен, лог прочитан,
  ожидание сверено с фактом; расхождение разбирается.
- Документация правится вместе с кодом; производные артефакты
  пересобираются и не коммитятся как истина.

## Практики стека проекта

- **Python.** Только stdlib для движка и валидаторов; внешние
  зависимости — решением оператора. Аннотации типов, `pathlib` для
  путей, явный `encoding="utf-8"` во всех вводах-выводах; вывод в
  UTF-8 независимо от локали. Конфиги — данные с голыми токенами;
  отказ — именованный, с честным exit-кодом.
- **Тесты.** pytest; у теста законная цель и трассировка
  ([testing.md](testing.md)); матрица идёт с мутационной или негативной
  пробой; ожидаемое значение — из независимого источника.
- **KB.** Markdown + git — источник истины; frontmatter и типизированные
  ссылки по онтологии, индекс папки связывает каждый документ;
  `.gitmark/` и карты — производные, не коммитятся.
- **Git.** Изолированный worktree под изменение; атомарные коммиты
  с осмысленным сообщением; слияние fast-forward, когда история линейна;
  производные и эфемерные файлы — в `.gitignore`.
- **DSH.** Подчинённые сессии — `subagent` (spawn) с явными маршрутом
  и уровнем из реестра; решения оператора — ask-инструментом хоста,
  один вопрос с вариантами и рекомендацией.
