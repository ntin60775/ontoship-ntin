# Справочники

- [sources.md](sources.md) — три источника основной идеи, что было взято и что
  оставлено.
- [testing.md](testing.md) — spec-, инвариантные и target-тесты; артефакт
  доказательства и разбор расхождений; доказательство ESEM 2026, планка
  качества и агентный цикл.
- [harnesses.md](harnesses.md) — канонический корень `.agents/skills`
  (единственный канал — установщик; ZCode-рельсы сняты) для zcode,
  DSH и Qoder: матрица, ранги, `AGENTS.md`, доказательства из исходников;
  панель, онто-док, цепочка и проекции на DSH, Qoder — пробел.
- [review-roles.md](review-roles.md) — контракты ревью-ролей базового набора,
  вход и выход роли, регламент паков контуров.
- [pack-contract.md](pack-contract.md) — контракт паков стандартов API v1:
  манифест, стандарты, чек-листы ролей, гейты как данные; проектный
  носитель, валидация и исполнение гейтов ядром.
- [text-style.md](text-style.md) — канон текстов: скиллы, правила, справочники,
  сообщения гейтов.
- [baseline-standards.md](baseline-standards.md) — базовые стандарты инженерии
  и стека из знаний модели; нижний приоритет норм, утверждён оператором.

- Справочник динамического allowlist пресетов DSH перенесён в team-бандл
  (core-team-boundaries 03): носитель —
  `ontoship-team/docs/reference/dsh-preset-allowlist.md`.
