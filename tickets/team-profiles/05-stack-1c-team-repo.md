# 05: Стековая специализация 1C — репо ontoship-team-1c

**Спека:** [team-profiles](../../docs/plans/team-profiles.md), «Готово» 4.

**Блокируется:** 01, 02

**Что построить:** новое стековое репо `ontoship-team-1c` в тим-контуре:
пресеты `1c-architect`, `1c-orchestrator`, `1c-executor` (копия
composition team-бандла + дельта: персона, доставка контура); team-id не
переопределяются. Доставка/гейты `dsh-1c-contour` переиспользуются как
зависимость. В 1C-DSH — **минимальный аддитивный шов**: фильтр доставки
становится конфигурируемым набором id (дефолт `1c` сохраняется,
существующий контур цел). Все инструменты 1C-DSH (15 скиллов контура +
Юника + 3 команды + MCP unica/1c-testpilot/1c-db/1c-kd + гейты) доступны
всем трём ролям; дифференциация позже. Паритетный тест против
пинованного `teamVersion`. Запись в `executors.json`; судьба legacy `1c`
названа. Первый шаг тикета — уточнение переиспользования/шва (до постройки).

**Кросс-репо:** в 1C-DSH свой тикет/спека/приёмка; этот тикет несёт
адрес изменения, ребро зависимости и ссылку на доказательство, ждёт
чужого мержа; чужой код здесь не коммитится.

**Демо-путь:** 1C-сессия с `1c-executor` получает скиллы/MCP/гейт
контура; team-architect — нет; паритетный тест зелёный.

**Критерии приёмки:**

- [ ] Репо ontoship-team-1c — артефакт: package.json, три пресета
      (копия team-composition + дельта); ожидание: «Готово» 4; на базе
      репо нет.
- [ ] Аддитивный шов 1C-DSH — артефакт: diff 1C-DSH (конфигурируемый
      фильтр id, дефолт 1c цел) + unit-тест (три id получают доставку,
      1c работает, team-architect — нет); ожидание: «Готово» 4; на базе
      фильтр захардкожен (красная проба для новых id). Кросс-репо:
      адрес+ребро+ссылка на доказательство, чужая приёмка.
- [ ] Паритет — артефакт: паритетный тест против пинованного
      teamVersion; ожидание: «Готово» 4, 11; на базе теста нет.
- [ ] Реестр и legacy — артефакт: запись в executors.json, названная
      судьба 1c; ожидание: «Готово» 4; на базе записи нет.
- [ ] Live 1C — артефакт: 1C-сессия, наблюдаемые скиллы/MCP/гейт у
      1c-executor и отсутствие у team-architect; ожидание: контур
      доставлен; на базе нет.
