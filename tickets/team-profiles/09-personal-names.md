# 09: Личные имена агентов — генерация и осознание

**Спека:** [team-profiles](../../docs/plans/team-profiles.md), «Готово» 1
(ревизия решением оператора 2026-11-13), уточнение запроса авто-имени.

**Блокируется:** 02 (team-бандл с плагином авто-имени существует).

**Блокирует:** 06 (релиз несёт механизм имён).

**Что построить:** замену ролевого авто-имени личными псевдореальными
именами. Запрос оператора: семантические имена («Архитектор»,
executor-2) не запоминаются и сливаются при трёх параллельных проектах;
каждый ролевой агент (корневой и ребёнок) получает личное имя, которое
он осознаёт — имя инжектится в контекст, агент называет себя под ним.

- Генератор: пул псевдореальных имён + seed-PRNG (seed от id сессии и
  соли), БЕЗ реестра уникальности (решение оператора: пересечения
  маловероятны). В одном дереве субагентов уникальность имени проверяет
  хост — при отказе генерация повторяется с другой солью.
- Хост-плагин team-бандла (расширение авто-имени тикета 01): при
  создании агента генерирует имя, инжектит его в контекст скоупированной
  секцией/переменной системного промпта («Тебя зовут …») — имя в
  контексте с первого хода; заголовок сессии — «Имя · Роль» (роль
  остаётся видна). Механизмы DSH сверены: `systemPrompt.section()/
  variable()` на скоуп агента, `agent/created`, creation-time
  композиция скоупа (разведка точного подключения — шаг тикета).
- Имя дерева (`name` спавна): разведка механизма передачи
  сгенерированного имени спавну (сервис/инструмент плагина для
  спавнящей роли либо перехват); механизма нет — норма в персоне и
  названный пробел, без тихой подмены.
- Ревизия спеки: «Готово» 1 и «Уточнения нарезки» (авто-имя) под личное
  имя, решение оператора в таблицу решений — одним изменением с кодом.

**Демо-путь:** новая сессия с пресетом architect — заголовок «Имя ·
Архитектор», агент в ответе называет себя личным именем; две сессии
одной роли — разные имена; ребёнок спавнится с личным именем и
осознаёт его.

**Критерии приёмки:**

- [ ] Генератор — артефакт: unit-тесты (детерминизм от seed, разные
      имена у разных сессий, пул, повтор при коллизии в дереве);
      ожидание: псевдореальные имена без реестра; на базе генератора
      нет.
- [ ] Инъекция в контекст — артефакт: контрактный тест + живой лог
      системного промпта (секция/переменная с именем); ожидание: агент
      осознаёт имя с первого хода; на базе инъекции нет.
- [ ] Заголовок — артефакт: live-сессия, заголовок «Имя · Роль»;
      ожидание: параллельные проекты различимы в боковой панели; на
      базе ролевой заголовок тикета 01.
- [ ] Имя ребёнка — артефакт: live-спавн с личным именем и осознанием,
      либо названный пробел с итогом разведки; ожидание: ребёнок
      адресуется личным именем; на базе имя — дисциплина спавнящей
      роли.
- [ ] Ревизия спеки — артефакт: diff «Готово» 1, «Уточнения нарезки»,
      таблицы решений; ожидание: спека несёт уточнённое требование;
      на базе ролевое авто-имя.
