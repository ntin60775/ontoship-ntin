# Kanban юнита team-profiles

Производный вид: таблица, вычисленная оркестратором из тикетов и
блокирующих рёбер `tickets/team-profiles/`. Колонка blocked вычисляется
из рёбер (незакрытые блокеры), не проставляется руками; ready-frontier
читается колонкой ready. Источник истины — тикеты; файл
перегенерируется при смене статусов. Статусы: done — выполнен и принят
автоприёмкой, running — в работе, ready — все блокеры закрыты,
blocked — есть незакрытые блокеры.
