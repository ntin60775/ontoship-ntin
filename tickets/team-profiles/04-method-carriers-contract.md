# 04: OntoShip-носители и метод-контракт

**Спека:** [team-profiles](../../docs/plans/team-profiles.md), «Готово» 6.

**Блокируется:** 02, 03

**Что построить:** скилл `chain` — контекстный промпт и проверка
`methodContract` (версия 1) через сервис плагина реестра, остановка с
вопросом при mismatch/отсутствии. Init называет team-бандл ссылкой в
§5/отчёте (без имени личного репо и литералов маршрутов). Содержательная
правка канона, зеркала `method-phases`, `harnesses.md` (уполномочена
решением 9); приписка-ревизия решения 2 `standards-autoship` И строки
«Рамок» одним изменением. `methodContract` в манифесте team-бандла,
эталон — релиз метода, правило bump.

**Демо-путь:** mismatch `methodContract` → chain останавливается с
вопросом; совпадение → продолжает; ссылка init на месте; якоря паритета
канона/зеркала зелёные.

**Критерии приёмки:**

- [ ] Проверка метод-контракта — артефакт: текст chain + живая проба
      (mismatch → стоп с вопросом, совпадение → продолжение) через
      сервис плагина; ожидание: «Готово» 6, 9; на базе проверки нет
      (поведенческая проба).
- [ ] Ссылка init — артефакт: текст §5/отчёта init + якорный тест
      (ссылка есть, имени репо и литералов маршрутов нет); ожидание:
      «Готово» 6, 15; красная проба на базе.
- [ ] Канон/зеркало/harnesses + приписка — артефакт: тексты + якоря
      canon_sync; приписка решения 2 и строка «Рамок» standards-autoship
      одним изменением; ожидание: «Готово» 6, 14; красная проба на базе.
