# 07: Живая проба полного потока на 1C-DSH

**Спека:** [team-profiles](../../docs/plans/team-profiles.md), «Готово» 8,
решение 17.

**Блокируется:** 06

**Что построить:** живая проба полного потока в temp-проекте с
`1C-DSH`. Профиль назван (temp `DSH_HOME`/копия или рабочий с
before/after sha256); `executors.json` записан ДО установки team-бандла
(или явный reload после записи); порядок установки и точки рестарта
названы. Поток: `1c-architect` → план-гейт → проекции → нарезка →
`1c-orchestrator` выбирает `1c-executor` по реестру → цепочка →
ревью-панель (четыре роли из `config.toml`, один прогон, вердикты) →
автоприёмка → финишная приёмка. Один игрушечный тикет с
1C-содержимым и ожидаемым контурным наблюдением (скиллы/MCP/гейт на
1C-правке); scout спавнится и наблюдается. Чек-лист «шаг → артефакт →
ожидание» с путями, ids, хешами, логами, ask-записями; durable-копия
финального отчёта. Бюджет — ex-ante предел + измеренный факт + стоп по
нормам chain; доска опциональна, не гейт.

**Демо-путь:** артефакты пробы (сессии, коммиты, отчёты) в этом тикете +
durable-отчёт; игрушечный юнит прошёл весь поток.

**Критерии приёмки:**

- [ ] Полный поток — артефакт: чек-лист шаг→артефакт→ожидание
      (ids сессий: 1c-architect, проекции, 1c-orchestrator, 1c-executor,
      панель; коммиты; ask-записи; вердикты панели; автоприёмка;
      финишная приёмка); ожидание: «Готово» 8, 17; на базе ролей нет.
- [ ] 1C-содержимое — артефакт: игрушечный тикет с 1C-правкой +
      контурное наблюдение (скиллы/MCP/гейт); ожидание: 1C-специализация
      доказана; на базе нет.
- [ ] Scout — артефакт: спавн scout в пробе; ожидание: scout работает;
      на базе нет.
- [ ] Отрицательные условия — артефакт: отчёт (оператор не читал и не
      писал код, других ручных гейтов кроме трёх нет, циклов правок
      нет); ожидание: «Готово» 8.
- [ ] Бюджет и профиль — артефакт: ex-ante предел + измеренный факт +
      стоп; before/after sha256 профиля; ожидание: «Готово» 8.
