# 06: Релиз и поставка team-бандла

**Спека:** [team-profiles](../../docs/plans/team-profiles.md), «Готово» 7.

**Блокируется:** 03, 04, 05

**Что построить:** semver-тег team-бандла; stable git-пин полным
40-символьным коммитом / dev `link:`; установка из пина в temp-профиль
и новая сессия с пресетами; `teamVersion` пинован в стеке
(`ontoship-team-1c`). Маркетплейс в этом юните не делается: отдельный
DSH-индекс маркета и CI validate — названный пробел контур-юнита.
Два репо: роли (`ontoship-team`) и стек (`ontoship-team-1c`).

**Демо-путь:** установка из git-пина в temp-профиль проходит, новая
сессия показывает пресеты (composition).

**Критерии приёмки:**

- [ ] Тег и пин — артефакт: semver-тег, git-пин полным коммитом;
      ожидание: «Готово» 7; на базе тега нет.
- [ ] Установка из пина — артефакт: лог установки в temp-профиль,
      композиция новой сессии; ожидание: пресеты монтируются из пина;
      на базе нет.
- [ ] teamVersion в стеке — артефакт: манифест стека с teamVersion;
      ожидание: «Готово» 7, 11; на базе нет.
- [ ] DSH-индекс маркета — названный пробел контур-юнита (не критерий
      этого тикета).
