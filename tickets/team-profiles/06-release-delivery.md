## Уточнение релиза (до постройки)

- **Тег и пин.** Версия релиза — `0.1.0` из `package.json`; annotated-тег
  `v0.1.0` ставится на финальный merge-коммит (с правками панели).
  Правило версии до 1.0.0: MINOR — новые роли, механизмы и ломающие
  изменения, PATCH — совместимые правки; тег = `v` + `version`.
- **lib в git — условие пина.** Бандл ставится из git-пина без
  build-шагов: git-зависимость, которой нужен build, pnpm блокирует
  политикой (`ERR_PNPM_GIT_DEP_PREPARE_NOT_ALLOWED`, проверено).
  Поэтому `lib/` (14 файлов, 92K) входит в релизный коммит; тест
  `lib.spec.ts` сторожит свежесть сборки и цели экспорта.
- **Адрес пина.** Remote у team-репо нет; проверенный fetchable-адрес —
  локальный `git+file:///<путь>#<commit>`. Публичный remote и DSH-индекс
  маркета — названный пробел контур-юнита (не критерий).
- **Dev-канал.** В профиле DSH — `link:` (решение 13); dev-зависимость
  стека — `file:../ontoship-team` (npm-копия без live-связи), потому что
  npm не поддерживает `link:`. Расхождение названо, паритет читает
  team-бандл из git-пина, а не из копии.
- **Legacy (leads 09).** Строка `ontoship-team` и корневой модуль
  `src/index.ts` удалены; корневой экспорт указывает на
  `ontoship-team/names`. Живой профиль держит старое поколение модулей:
  снятие строки видно после рестарта (тикет 07).
