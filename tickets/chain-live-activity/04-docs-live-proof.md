# 04: Документация и живая проба полного пути lease

**Спека:** [chain-live-activity](../../docs/plans/chain-live-activity.md),
«Готово» 7, 8, 9; решения 3, 8.

**Блокируется:** тикеты 01, 02, 03.

**Что построить:** документация плагина — DESIGN.md (активность —
машинный реестр, новые элементы), ARCHITECTURE.md (таблица
формат→писатель, правила истины, задел ActivitySource, параллельность,
пользовательские фильтры), CONTINUE.md, README.md, DETAIL.md,
AGENTS.md, description локалей: утверждения «ничего не хранит / только
чтение» правятся (доска читает, host-инструменты пишут lease). Метод:
приписка о реестре активности в `docs/reference/harnesses.md`. Живая
проба: мини-цепочка одного игрушечного тикета в temp-проекте, фикстура
по прецеденту `/tmp/sa06-chain` (ядро и пак копией, init, игрушечный
юнит, запись гейта проекций и приёмка нарезки — «установка пробы»,
названный пробел); preflight — host перезапущен, инструменты
`ontoship_run_*` присутствуют; именованная пауза для осмотра доски
оператором. Закрывающий набор двух репо.

**Демо-путь:** живая мини-цепочка: доска в сессии оркестратора,
dispatch при выдаче, lease исполнителя по фазам, финиш; оператор
подтверждает вид на паузе.

ожидание: фазы starting → working → review → gates → merge → accepted
в run-файле; runId dispatch и run совпадают; путь lease = boardRoot
оркестратора; heartbeat до панели (рост updatedAt); шапка «в работе 1»
во время прогона и 0 после; dispatch-only «выдан, сигнала нет» до
первого update; проба без lease-артефактов доказательством не
считается.

**Критерии приёмки**:

- [ ] Документация — артефакт: диффы доков плагина и harnesses.md;
      ожидание: read-only-утверждения исправлены во всех названных
      носителях, таблица формата и правила истины в ARCHITECTURE.md,
      задел фильтров/ActivitySource назван; доки плагина — чтение и
      тесты плагина, KB метода — `lint --strict` чист.
- [ ] Живая проба — артефакт: идентификаторы сессий оркестратора и
      исполнителя, lease-файлы (dispatch и run), подтверждение вида
      оператором на паузе; ожидание: все ожидания демо-пути выше
      сопоставлены с артефактами; preflight инструментов записан.
- [ ] Закрывающий набор — артефакт: выводы прогонов тестов плагина
      (модель, клиент, host, дизайн) и контрактных тестов метода,
      красные пробы на два базовых коммита (`ad4b7d8` плагина,
      `2116209` метода); ожидание: наборы зелёные, краснота названа.
