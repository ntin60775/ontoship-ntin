# 02: Правила истины и поповер прогонов

**Спека:** [chain-live-activity](../../docs/plans/chain-live-activity.md),
«Готово» 3, 4; решения 1, 3, 5.

**Блокируется:** тикет 01 (реестр, инструменты, базовая модель и UI).

**Что построить:** правила истины поверх первого выстрела: stale по
TTL (1800/3600 review) с таймером UI и управляемыми часами — протухание
без событий реестра; конфликт двух живых прогонов на тикет; orphan
(run без dispatch) и lease на заблокированный/отсутствующий тикет —
бейджи-несогласованность, не жив; dispatch без run — «выдан, сигнала
нет» сразу, без ожидания TTL; idle не жив и не в шапке; скоуп чужого
юнита; проза active колонку не задаёт — существующие зелёные
prose-active тесты переписываются. UI: поповер прогонов (роль, модель,
сессия, тикет, фаза, давность сигнала, branch, note), stale-бейдж «нет
сигнала N мин», конфликт-бейдж, бейдж-несогласованность, dispatch-only
состояние, idle «между тикетами»; локали; сборка client.js.

**Демо-путь:** фейковые lease с управляемыми часами в client-тесте:
протухший lease → карточка «В работе» с бейджем «нет сигнала N мин» и
K=0 в шапке; два живых прогона → конфликт-бейдж; dispatch без run →
«выдан, сигнала нет»; поповер несёт branch и note.

ожидание: доска не врёт о живости — протухшее видно, конфликт видно,
выданное без сигнала видно; на базе правила отсутствуют — тесты
красные.

**Критерии приёмки**:

- [ ] Правила истины — артефакт: лог модельных тестов с управляемым
      now; ожидание: stale на границе 1800/3600, конфликт двух живых,
      orphan и заблокированный тикет — несогласованность и не жив,
      dispatch-only сразу, idle не жив, чужой юнит отскоуплен,
      prose-active переписан (проза не задаёт колонку); на базовом
      коммите плагина `ad4b7d8` кейсы падают.
- [ ] UI правил и поповер — артефакт: лог client-тестов по дереву
      vnode с управляемыми часами и лог дизайн-теста; ожидание:
      stale-бейдж, конфликт-бейдж, бейдж-несогласованность,
      dispatch-only, idle-строка, состав поповера (branch, note,
      давность), шапка K считает только живых; на базе `ad4b7d8`
      тесты падают.
