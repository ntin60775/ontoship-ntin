## Находки и триаж (после дедупликации)

Подтверждены и внесены в спеку решением оператора «править всё»
(ask 2026-11-12):

- **P1. idle/терминальные фазы без писателя и переходов** (time-risk,
  coverage, authority, proof). Решение: терминальные accepted/aborted/
  failed определены; idle пишет исполнитель в свой последний run-файл
  после финиша и между тикетами, не жив; пенсия → новый runId, старый
  idle; остановка ship → aborted с note. Готово 1, 3, 5, 6.
- **P1. Ложный stale живого прогона на длинном шаге** (time-risk).
  Решение: heartbeat на внутренних рубежах — лог тестов (шаг 3),
  старт/финиш пакетов панели и после правок (шаг 4), выводы гейтов
  (шаг 6). Готово 5; значения TTL 30/60 не менялись.
- **P1. Stale без владельца времени** (proof). Решение: таймер UI ~30 с
  пересчитывает свежесть без событий реестра; client-тест с
  управляемыми часами. Готово 4.
- **P1. Механизм записи и триггер scope:local не определены; raw fs
  обходит файловую политику; boardRoot — произвольный путь** (authority,
  proof). Решение: raw fs по прецеденту, boardRoot валидируется, ошибка
  ФС → local; обход сессионной политики — названное ограничение
  доверия. Готово 2, Ограничения.
- **P1. Живая проба без ожиданий и фикстуры; может пройти на named
  gap; перезапуск хоста не назван** (proof, authority). Решение:
  фикстура по прецеденту sa06-chain, preflight инструментов и
  перезапуск хоста, ожидания по фазам/runId/пути/шапке/heartbeat,
  именованная пауза для осмотра доски; проба без lease-артефактов не
  доказательство. Готово 8.
- **P2. runId — bearer-токен, роль не привязана** (authority).
  Решение: dispatch пишет executor.session, update сверяет caller,
  несовпадение → отказ. Готово 2.
- **P2. TTL-писатель не назван** (coverage). Решение: dispatch 1800,
  update review 3600, тесты с точными числами. Готово 1–3.
- **P2. runId только в первом сообщении против продолжаемой сессии**
  (coverage). Решение: runId и boardRoot в каждом сообщении выдачи и
  в handoff пенсии. Готово 6.
- **P2. Уборка в двух местах, второй писатель, глобальна, без часов**
  (authority, coverage, time-risk). Решение: уборка только в dispatch,
  того же юнита, терминальные и протухшие нетерминальные по updatedAt
  старше 24 ч, живые не трогает; GC-исключение названо. Готово 2, 6.
- **P2. Третий бейдж и dispatch-only состояние не доведены до UI**
  (coverage). Решение: бейдж-несогласованность и «выдан, сигнала нет»
  сразу (без TTL) в Готово 3–4, локали, client-тесты.
- **P2. Скоуп юнита против формулировки Рамок о фильтрах** (coverage,
  authority). Решение: скоуп до текущего юнита — v1-код (существующее
  поведение), пользовательские фильтры — задел. Рамки, Готово 3, 7.
- **P2. read-only-утверждения README/DETAIL/AGENTS/локалей не названы
  носителями правки** (coverage). Решение: добавлены в Готово 7.
- **P2. Поля схемы без писателя/потребителя; таблицы поле→файл→писатель
  нет; dispatch не знает branch/worktree** (coverage, authority,
  proof). Решение: таблица в Готово 1; branch/worktree — аргументы
  update из cwd исполнителя, потребители — поповер (branch, note);
  executor.session — из спавна на dispatch.
- **P2. Гонка пенсии и lost updates; tmp не уникален** (authority).
  Решение: пенсия → новый runId (старый idle), уникальное имя tmp,
  один писатель + привязка caller; поле seq снято, порядок по
  updatedAt (упрощение, находка proof). Готово 1–3, 6.
- **P2. Ручной /ship без runId** (authority). Решение: self-dispatch
  на шаге 1, boardRoot = cwd. Готово 5.
- **P2. Сборка client.js не названа; UI-тесты не краснеют по существу**
  (authority, proof). Решение: build.mjs → client.js в носителях,
  client-тесты по дереву vnode с управляемыми часами; дизайн-тест —
  охрана литералов, ограничение названо. Готово 4, 9.
- **P2. Переходы фаз не доказаны носителями скиллов** (proof).
  Решение: контракт-тесты сторожат текст, переходы доказывает живая
  проба; разделение названо. Готово 5, 6, 8.
- **P3. Атомарность без ФС-носителя** (proof) → перенесена в Готово 2
  (host-тесты).
- **P3. Часы уборки не названы** (proof) → updatedAt, не mtime.
  Готово 2.
- **P3. Перепись зелёных prose-active тестов не названа** (proof) →
  названа в Готово 3 и 9.
- **P3. Один базовый коммит на два репо; lint не видит доки плагина**
  (proof) → два базовых коммита в Готово 9; доки плагина — чтение и
  тесты, Готово 7.
- **P3. boardRoot под двумя именами** (coverage) → терминология
  сведена в Готово 1.
- **P3. Бейдж-гигиена прозы не определён в/вне v1** (coverage) →
  задел, не v1 (решение оператора, триаж). Рамки.

Отвергнуты:

- «unit-фильтр вопреки Рамкам» как дефект (authority): скоуп до
  текущего юнита — существующее поведение доски, не пользовательский
  фильтр; столкновение формулировок снято правкой Рамок.
- «ctx.fs всегда denied → local становится нормой» (authority):
  гипотеза о политике, не факт; спека фиксирует raw fs по прецеденту и
  названное ограничение доверия, механизм проверяется при реализации.

Оверинжиниринг: находок, требующих работы сверх цели, не подтверждено;
два упрощения внесены (seq снят, бейдж-гигиена — задел).
