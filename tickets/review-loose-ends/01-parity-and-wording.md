# 01: сторож паритета и нейтральные формулировки

**Спека:** [docs/plans/review-loose-ends.md](../../docs/plans/review-loose-ends.md)

**Что построить:** тест паритета в `tests/test_install.py`: машинный
источник — массив `SKILLS` из `scripts/install.sh`, с ним сверяются все
носители перечня — бандл-строки `skills/README.md` (равенство в обе
стороны), перечисление в usage-строке установщика, кортеж теста (разобранный
массив называется не `SKILLS`) — плюс связка «Раскладка» →
`skills/README.md` в `AGENTS.md` и существование самого файла; числительные
«nine» уходят из установщика и имён тестов; мутационные пробы —
коммитируемые тесты (убранная строка индекса, фантомный бандл, оборванная
связка, удалённый индекс). «Реестр ролей ревью» → «реестр ролей» и
заголовок «Бутстрап ролей ревью» → «Бутстрап ролей» в `skills/init/SKILL.md`;
контракт `tests/test_skill_init.py` правится тем же изменением, запрещает
обе старые формулировки и несёт пробу возврата каждой. Ассерт-сторож
счётчика в `tests/test_install.py`: `docs/reference/harnesses.md` без цифр
и числительных перед «скилл»/«бандл»; перечисление «девять скиллов»
заменить указателем на `skills/README.md`. Приписка-вставка в
`docs/plans/review-config.md` у строк «Роли ядра — пять» и «восемь
бандлов»: ролей шесть с `onto-doc` (добавлен `curator`), бандлов девять.

**Блокируется:** —

**Демо-путь:** красные на базовом коммите контракт формулировок и сторож
счётчика → зелёные после; пробы паритета красят испорченный носитель;
diff приписки в тикете.

**Критерии приёмки**:

- [x] паритет сторожится — артефакт: прогон тестов паритета на базовом
      состоянии и мутационные пробы как тести; ожидание: паритет зелёный
      на базе (он выполняется), каждая проба — убранная строка индекса,
      фантомный бандл в перечне, оборванная связка, удалённый
      `skills/README.md` — краснит; ни число, ни список в тесте
      не захардкожены, «nine» отсутствует в установщике и именах тестов
      (спека, «Готово» 1)
- [x] формулировки нейтральны — артефакт: прогон контракта
      `test_skill_init.py` на базовом коммите и после правки; ожидание:
      красный на базе (запрещённые формулировки присутствуют), зелёный
      после; «реестр ролей ревью» и «Бутстрап ролей ревью» отсутствуют
      во всех местах `skills/init/SKILL.md`, проба возврата каждой
      формулировки краснит («Готово» 2)
- [x] приписка на месте — артефакт: diff `docs/plans/review-config.md`
      в тикете; ожидание: одна вставка у двух названных строк (формат —
      по прецеденту приписки к решению 10: имя юнита, дата, решения),
      подъём `updated`, строки решений не изменены («Готово» 2, решение 2)
- [x] счётчик под сторожем — артефакт: прогон ассерта на базовом коммите
      и после; ожидание: красный на базе (строка «девять скиллов»
      существует), зелёный после, состав назван указателем на
      `skills/README.md` («Готово» 3)
- [x] прогоны записаны — артефакт: строка в тикете; ожидание: критик
      `dwfrun-6c6159cc` («план пригоден после правок», закрыт решением
      оператора «править всё»), панель — идентификатором прогона в ship
      («Готово» 4)
- [x] разбор расхождений ожидание/факт — строка «не было» или разбор
      ([testing.md](../../docs/reference/testing.md))

**Доказательства (исполнитель, до merge):**

- Критерии 1–2 и 4, красный на базовых носителях (тесты добавлены,
  носители ещё нет): `python3 -m pytest tests/test_install.py
  tests/test_skill_init.py -q` → **6 failed, 33 passed**. Красят: сторож
  счётчика (`test_harnesses_carries_no_bundle_count`,
  «a count snapshot before a counted noun: 'девять скиллов'») и контракт
  формулировок — `forbidden wording 'реестр ролей ревью'` и
  `forbidden wording 'бутстрап ролей ревью'` — в четырёх носителях
  контракта и новом мутационном тесте. Паритет зелёный на базе: обе
  проверки `test_bundle_carriers_stay_in_parity_with_the_installer`
  и `test_parity_can_fail` среди 33 passed.
- Зелёный после правки носителей: тот же прогон → **39 passed**.
  Мутации `test_parity_can_fail` исполняются в финальном дереве:
  убранная строка индекса → `parity: skills/README.md misses the
  kb-curate bundle`, фантомный бандл → `lists a phantom extra-skill
  bundle`, оборванная связка → `the AGENTS.md layout row does not point
  at skills/README.md`, удалённый индекс → `skills/README.md is missing`.
  Мутации `test_registry_wording_contract_can_fail`: возврат «реестр
  ролей ревью» в теле и в description (с заглавной — доказана
  нечувствительность к регистру), возврат заголовка «Бутстрап ролей
  ревью» — каждый ловится запретом формулировки. Ни число, ни список
  в `_parity_errors` не захардкожены: источник — разобранный массив
  `readonly SKILLS=(…)` установщика, кортеж теста читается из его же
  текста, имя разобранного массива — `bundles`, не `SKILLS`.
- «nine» отсутствует: `grep -rn "nine" scripts/install.sh
  tests/test_install.py` — единственное вхождение в docstring-цитате
  спеки onto-doc (`spec: … the install channel carries nine`), имена
  тестов и установщик чисты; имена переименованы
  (`test_fresh_install_links_every_bundle_and_writes_nothing_else`,
  `test_check_on_a_fresh_project_names_every_missing_skill_without_writing`).
- Критерий 3, diff приписки `docs/plans/review-config.md`:

  ```diff
   - Ядро растёт на один скилл: `critic` (модельный — запускается агентом сразу
     после приёмки последнего тикета юнита); установщик ставит восемь бандлов
     вместо семи.
  +  Приписка юнита onto-doc (2026-10-30, решение 3 его спеки): счёт строк выше
  +  устарел — ролей ядра шесть, добавлен `curator`; бандлов девять: `critic` —
  +  восьмой, `onto-doc` — девятый.
  ```

  Плюс подъём `updated: 2026-10-30` → `2026-11-01`; строки решений
  и строки «Роли ядра — пять» / «восемь бандлов» не тронуты.
- Критерий 4, носитель: `harnesses.md` — перечисление заменено указателем
  «состав называет индекс [skills/README.md](../../skills/README.md)»;
  сторож зелёный в составе 39 passed.
- Критерий 5, прогоны: критик нарезки — `dwfrun-6c6159cc` («план пригоден
  после правок», 1 P1 / 7 P2 / 3 P3, закрыт решением оператора «править
  всё» 2026-11-01, правки в `96a5364`); панель — `dwfrun-…` (строка
  дополнена после прогона, до merge).
- Полный набор: **366 passed = 362 + 4** (паритет, пробы паритета, сторож
  счётчика, пробы формулировок); `lint --strict` — `✓ чисто (72 файла · —)`;
  `gitmark.py index` — 72 файла, 340 чанков, 178 ссылок. Живой
  `install.sh --check` основного checkout — после merge установщиком main:
  ссылки основного checkout указывают на его собственные бандлы, проверка
  из worktree честно называла drift.
