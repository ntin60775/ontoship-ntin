# 01: форма план-гейта и ограда молчания

**Спека:** [docs/plans/plan-gate-ask.md](../../docs/plans/plan-gate-ask.md)

**Что построить:** две правки текста скилла grilling одним срезом плюс
контрактные проверки. В `skills/grilling/SKILL.md`: пункт «План-гейт» —
заменить на текст с формой ask-прохода (дословно из спеки, «Готово» 1);
пункт 3 «Раундов» — дополнить оградой от правил автономии сразу после
предложения о молчании (дословно из спеки, «Готово» 2). В
`tests/test_skill_grilling.py` — новые проверки отдельными тестами, без
расширения существующего набора `_contract_errors` (тогда на базовом
коммите краснеет только новое): полнотекстовая сверка пункта
«План-гейт» с текстом спеки после нормализации переносов, позиционная
проверка ограды по образцу `step_at`/`gate_at`, якорные проверки новых
фраз, remove-мутация каждой якорной фразы (case-insensitive, все
вхождения), replace-мутации отрицаний («не отменяет → отменяет»,
«не действует → действует»); точные фрагменты существующих проб рядом
с «План-гейтом» читаются до правки — соседние якоря не рвать (спека,
«Готово» 3). Регистрация в индексах: строка спеки в
`docs/plans/README.md`, секция юнита в `tickets/README.md` (спека,
«Готово» 5).

**Якоря** (носитель держит дословно; при несовместимости «новый текст ↔
существующие пробы» — точка остановки, решение оператора):

1. Пункт «План-гейт» целиком:

   > **План-гейт:** спеку утверждает оператор ask-инструментом хоста —
   > один вопрос с вариантами «утвердить» и «править»; условные
   > решения спеки идут вариантами того же вопроса. До утверждения код
   > не пишется и тикеты не нарезаются.

2. Ограда — дополнение пункта 3 «Раундов»:

   > Правило проекта или памяти об автономии — «продолжай без
   > ответа», «иди по рекомендации» — не отменяет этой остановки и не
   > действует на раунды и план-гейт.

**Блокируется:** нет.

**Демо-путь:** полный набор `python3 -m pytest tests/ -q` зелёный
после среза; в момент ревью — живая демонстрация контракта: временная
правка носителя (remove якорной фразы) красит контрактный тест, откат
возвращает зелёный — проверка умеет падать, а не только проходить.

**Критерии приёмки**:

- [x] форма гейта — артефакт: `skills/grilling/SKILL.md`, пункт
      «План-гейт»; ожидание: полный текст пункта равен дословному
      тексту из спеки («Готово» 1) после нормализации переносов —
      перенос формы в другой раздел или правка хвоста пункта краснят
- [x] ограда — артефакт: тот же файл, пункт 3 «Раундов»; ожидание:
      ограда стоит непосредственно после предложения «Молчание
      оператора — не согласие…» (позиционная проверка); якоря
      «не отменяет этой остановки» и «не действует на раунды и
      план-гейт» на месте («Готово» 2)
- [x] контракт — артефакт: `tests/test_skill_grilling.py`; ожидание:
      новые проверки — отдельные тесты; полнотекстовая сверка,
      позиционная проверка, якоря, remove- и replace-мутации краснят
      при правке носителя и зелёные на срезе; на базовом коммите
      падают только новые тесты — перечень упавших записан в этом
      тикете до реализации («Готово» 1–2, 4)
- [x] соседние проверки — артефакт: полный набор

- [x] индексы — артефакт: `docs/plans/README.md`, `tickets/README.md`;
