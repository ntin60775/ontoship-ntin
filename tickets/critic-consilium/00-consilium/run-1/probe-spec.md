# probe-export — тестовая спека для живой пробы

Фикстур для пробы консилиума, не KB-документ и не план-гейт.

## Цель

Экспорт отчёта в три формата: CSV, JSON, XLSX.

## Готово

- Экспорт CSV: файл создаётся, шапка совпадает с отчётом.
- Экспорт JSON: схема описана в приложении A.
- Экспорт XLSX: книга открывается, листы соответствуют разделам.
- Экспорт проверен.
- Система работает корректно.
- Добавить веб-панель мониторинга экспорта.
- Поддержать четыре формата.

## Рамки

- Только экспорт; веб-панель вне рамок.
- Поле `format` задаётся в конфиге; допустимые значения не
  перечислены.

## Ограничения

- Поле `format` не имеет списка допустимых значений.
- Тикет 02 (миграция) зависит от тикета 01 (экспорт).
- Тикет 01 блокируется тикетом 02.

## Контекст

- Отчёт формируется модулем `report-core`.
- Каждый формат экспортируется за минуту; полный экспорт трёх форматов
  занимает две минуты.
