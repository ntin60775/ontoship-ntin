# 01: корень установки `.agents/skills`

**Что построить:** `scripts/install.sh` ставит `kb-search`, `kb-curate` и `init` в
`<project>/.agents/skills` — один project-local корень для zcode, DSH и Qoder.
`--check` проверяет эту раскладку, выходит с кодом 0 на правильной установке и
предупреждает о legacy-записях `.dsh/skills`, `.zcode/skills` и `.qoder/skills`,
которые ведут в `skills/` этого репозитория. Legacy-записи он не удаляет.

**Блокируется:** ничем.

**Статус:** сделан (2026-10-21)

      на `<repo>/skills/<name>`; `--copy` создаёт отсоединённые каталоги там же.
- [x] Повторный запуск ничего не меняет; `--check` выходит с кодом 0 на правильной

печатает предупреждение о затенении и не удаляет ссылку.

## Доказательства (2026-10-21)

- **Поставлено:** `scripts/install.sh` (245 строк) ставит в `<project>/.agents/skills`
  и больше никуда; `tests/test_install.py` (284 строки, 11 тестов).
- **Поведение:** цель установки — `.agents/skills`; `--copy` кладёт отсоединённые
  каталоги туда же; preflight, идемпотентность и проверка копий не менялись.
  `--check` дополнительно сканирует `.dsh`, `.zcode` и `.qoder`: если корень
  `.dsh/skills` или запись `<root>/skills/<name>` — символическая ссылка в

  предупреждение называет ранги 100 и 200 и затенение `.agents`; код возврата не
  меняется, запись не удаляется.
- **Демо** (временный каталог): первый прогон — три `linked`; второй — три
  `unchanged`; `--check` — `check: ok`, код 0; добавлена ссылка
  `.dsh/skills/kb-search` → `--check` печатает предупреждение о затенении, всё ещё
  `check: ok` и код 0; ссылка осталась на диске после проверки.
- **Тесты:** `python3 -m pytest tests/test_install.py -q` → **11 passed**. Новые:
