# 01: правила приёмки — артефакт и ожидание в каждом критерии

**Спека:** [docs/plans/evidence-verification.md](../../docs/plans/evidence-verification.md)

**Что построить:** `skills/to-tickets/SKILL.md` — разделы «Срезы» и «Порядок»
обязывают каждый критерий приёмки тикета называть наблюдаемый артефакт (вывод
команды, строка лога, файл, живая проба) и ожидание из спеки; «тест зелёный» —
сигнал к чтению артефакта, не доказательство; квиз перед публикацией
спрашивает «что я увижу и где». `docs/reference/testing.md` — раздел
«Артефакт доказательства»: определение (артефакт + ожидание из спеки),
законные носители — автоматический прогон, вывод команды, строка лога, файл,
ручная проба с приложенным артефактом (решение 6 спеки), — и правило разбора
расхождений (решение 3): расхождение ожидание/факт разбирается до merge —
дефект → правка + target-тест, не дефект → записанный вывод «почему поведение
правильное», без расхождений — строка «не было»; неразобранное расхождение —
точка остановки ship.

**Критерии приёмки**:

- [x] контракт to-tickets требует артефакт и ожидание — артефакт: лог
      `pytest tests/test_skill_to_tickets.py -q` с новым утверждением против
      текста скилла базового коммита (скилл откатан; красный по отсутствию
      требования) и после правки (зелёный); ожидание: требование артефакта
      и ожидания из спеки стоит в обоих разделах («Срезы» и «Порядок»),
      квиз перед публикацией спрашивает «что я увижу и где»; мутационные
      пробы: потеря требования артефакта, потеря квиза, потеря раздела —
      каждая краснит
- [x] testing.md несёт раздел «Артефакт доказательства» — артефакт: вывод
      `search "артефакт доказательства"` (`gitmark.py search`),
      `docs/reference/testing.md` появляется в выдаче; ожидание: раздел
      называет законные носители из решения 6, правило разбора расхождений
      из решения 3 и обязывает каждый юнит переносить это правило в свои
      «Ограничения»; раздел связан из индекса папки
- [x] KB чист после правок — инвариантный охранник, на базе зелёный,
      краснота не обещается; артефакт: вывод `gitmark.py lint --strict`
      (код 0) и пересобранный индекс; ожидание: новые сироты отсутствуют,
      файлы не потеряны
