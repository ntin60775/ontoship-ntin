# Тикет 04 — Релизы и закрытие юнита

Блокируется: 03
Блокирует: —

Спека: [deliver.md](../../docs/plans/deliver.md), «Готово» 7–8,
решение 5. База нарезки: `40c0dc6` (ядро), `v0.2.0` (реестр).
Кросс-репо тикет (прецедент team-profiles): ядро ntin и репо
consumer-registry, два ship-контура в одном тикете.

## Задумка

Оба контура релизятся после пробы: ядро — тег `v0.8.0`, реестр — тег
`v0.3.0`; тег = tip соответствующего main после ff-слияния среза,
push по SSH, сверка ls-remote SHA main ↔ tag; чистые установки из
деревьев тегов доказывают самодостаточность релизных деревьев; юнит
закрывается записями в трекере и KB.

## Демо-путь

`git ls-remote origin` обоих репо: SHA main и тега совпадают; логи
чистых установок из деревьев тегов в temp (ядро — 11 бандлов,
`check: ok`; реестр — 1 бандл, `check: ok`); абзац юнита в
continue.md, секция в tickets/README, статус «закрыт» в индексе
планов; полный набор ядра зелёный, lint --strict чист. Красное на
базе: тегов v0.8.0/v0.3.0 нет.

## Критерии приёмки

1. Merge ядра (срезы тикетов 01/03 и правки панели) ff в main; тег
   `v0.8.0` на tip main; push main и тега по SSH; `ls-remote`: SHA
   main и тега совпадают. Артефакт: вывод ls-remote, git log.
   Ожидание: спека «Готово» 7, триаж G-17. На базе падает: тега нет.
2. Merge реестра (срез тикета 02 и правки панели) в registry main;
   тег `v0.3.0` на tip main; push по SSH; ls-remote SHA main ↔ tag
   совпадают. Артефакт: вывод ls-remote реестра. Ожидание: спека
   «Готово» 7. На базе падает: тега нет.
3. Чистая установка из дерева тега `v0.8.0` в temp: 11 бандлов,
   `check: ok`, deliver в составе; из дерева тега `v0.3.0`: один
   бандл, `check: ok`, grep zcode пуст. Установка из тега доказывает
   самодостаточность релизного дерева (не пины потребителей).
   Артефакт: логи установок, вывод --check. Ожидание: спека «Готово»
   7, триаж G-17. На базе падает: тегов нет.
4. Если правки панели после пробы тикета 03 тронули description
   deliver — повторная проба маршрутизации от тега (одна сессия,
   контур K2) либо названный пробел с решением оператора. Артефакт:
   diff description проба→тег, транскрипт повторной пробы или запись
   пробела. Ожидание: спека «Готово» 7, триаж G-12.
5. Закрытие юнита: абзац юнита в `docs/ops/continue.md` (факты
   тикетов, релизы, пробелы), секция юнита в `tickets/README.md`,
   статус «закрыт» в `docs/plans/README.md`; закрытые тикеты помечены
   сделанными с доказательствами. Артефакт: тексты записей, git diff.
   Ожидание: спека «Готово» 8. На базе падает: записей нет.
6. Контур зелёный: полный набор тестов ядра, `lint --strict` чист,
   selfhost `check: ok`; красные логи тикетов 01–03 собраны в
   evidence. Артефакт: выводы прогонов, индекс evidence. Ожидание:
   спека «Готово» 8.

## Ограничения

- Теги — только после merge соответствующего контура; тег на origin
  до merge запрещён.
- Пробелы юнита называются в закрытии: ask-ноги протокола не исполнены
  в пробе; acceptance[] deliver не заполняет; legacy-парк вне пробы;
  бэкап реестра вне v1; selfhost-реестр в ntin и backfill парка —
  первый реальный rollout после юнита (данные парка — факты
  оператора).
- Коммиты реестра до этого тикета локальные; push — здесь, по SSH.
