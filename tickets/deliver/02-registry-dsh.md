## Задумка

Репо consumer-registry превращается из ZCode-плагина маркета в
самостоятельный DSH-поставляемый бандл: свой install.sh (link/copy/check
одного бандла), схема/каркас/валидатор внутри каталога бандла, пути
`.zcode` → `.agents`, канал маркета снят, скилл в DSH-идиоме с
идемпотентным стартом ведения и предупреждением о потере файла.
Контракт данных `consumer-registry/1` не меняется.

## Демо-путь

`scripts/install.sh --copy <temp-продюсер>` ставит бандл; старт ведения
по скиллу создаёт `<temp>/.agents/registry.local.json` из каркаса и
добавляет строку gitignore (чужие строки целы); повторный старт — diff
пуст; валидатор зелёный на заполненном реестре (ненулевые
consumers/deploy_log); `grep -r zcode` по содержимому бандла пуст;
тесты репо зелёные; красная проба на `v0.2.0` — install.sh нет, пути
`.zcode`.

## Критерии приёмки

1. Свой `scripts/install.sh`: link/copy/check одного бандла
   `consumer-registry`, идемпотентен, пишет только `.agents/skills`,
   preflight отказывает вместо полуустановки (контур установщика
   ядра). Артефакт: вывод установки в temp-продюсер (link и copy),
   вывод --check. Ожидание: спека «Готово» 5. На базе падает:
   install.sh в репо нет.
2. Бандл самонесущий: `skills/consumer-registry/` несёт SKILL.md,
   `templates/` (схема, каркас, gitignore.snippet),
   `scripts/registry_check.py`; валидатор запускается из бандла и
   принимает путь файла и схемы. Артефакт: дерево бандла, прогон
   валидатора из установленного бандла. Ожидание: спека, тривиальное
   решение «бандл самонесущий». На базе падает: файлы вне бандла.
3. Пути `.agents`: дом файла — `<продюсер>/.agents/registry.local.json`;
   gitignore.snippet несёт `.agents/registry.local.json`; описательные
   тексты схемы/каркаса/докстринга несут новый путь; поля, структура,
   `const` версии, required-наборы схемы не изменились (сверка с
   `v0.2.0` по структурным ключам). Артефакт: diff схемы (только
   описательный текст), сниппет, текст каркаса. Ожидание: спека
   «Готово» 5, рамка G-8. На базе падает: пути `.zcode`.
4. ZCode-канал снят: `.zcode-plugin/`, `deploy.json` удалены;
   `grep -r zcode` по содержимому бандла пуст; пины новых путей в
   адаптированных тестах. Артефакт: вывод grep (пусто), дерево репо,
   прогон тестов. Ожидание: спека «Готово» 5, триаж G-21. На базе
   падает: литералы присутствуют.
5. Скилл DSH-идиомы: frontmatter `name`/`description`; старт ведения
   идемпотентен (повторный — diff пуст, строка gitignore не
   дублируется); шаг старта несёт предупреждение «снос `.agents`
   уничтожает реестр, бэкап вне v1»; правило сверки followups
   `done: false` перед поставкой сохранено. Артефакт: текст SKILL.md,
   diff повторного старта в temp-продюсере. Ожидание: спека «Готово»
   5, триаж G-20, G-27. На базе падает: идемпотентность и
   предупреждение не названы.
6. Тесты репо зелёные (адаптация существующих под новые пути, без
   nice-to-have); красная проба финальным набором на `v0.2.0` —
   failed по существу критериев. Артефакт: зелёный и красный логи.
   Ожидание: спека «Готово» 5, 8.
