# Тикет 01 — Бандл deliver и строка входа

Блокируется: —
Блокирует: 03

Спека: [deliver.md](../../docs/plans/deliver.md), «Готово» 1–2,
«Протокол deliver», «Контракт акта». База нарезки: `40c0dc6`.

## Задумка

В ядре появляется скилл `deliver` — полный протокол поставки/обновления
ядра в проекте X (источник, поиск X, состояние, канал, установка, init,
акт rollout через скилл реестра с absence-поведением и стартом ведения
при отсутствующем файле, отчёт фактами) и description, несущий семантику
интента «поставить/обновить/деплой OntoShip в проекте». Установщик
поставляет 11 бандлов; блок входа init получает строку команды;
selfhost-блок репо приводится к шаблону повторным init.

## Демо-путь

Каталог скиллов текущей сессии после selfhost-установки несёт `deliver`
с description; AGENTS.md репо несёт строку команды в блоке;
`scripts/install.sh --check .` — `check: ok` (11 бандлов);
`pytest tests/test_install.py tests/test_skill_init.py` зелёный;
красная проба на базе — паритет 11 против 10 и отсутствие строки блока
краснят.

## Критерии приёмки

1. Бандл `skills/deliver/SKILL.md` существует и несёт: description
   семантики поставки/обновления (без литералов парафраза «раскатай
   ядро в X»); протокол из спеки (источник install.sh: link-продюсер
   резолвит realpath бандла, copy-продюсер — ask о чекауте; поиск X;
   --check до обновления; warning установщика называется до
   утверждения «поставлено»; канал не меняется молча; relink — штатное
   действие; drifted-копия — отказ и остановка на ask; init после
   установки и при обновлении; акт по контракту акта; скилла реестра
   нет — пробел называется, fallback нет; файл реестра отсутствует при
   установленном скилле — старт ведения по правилам скилла, затем акт;
   отчёт фактами). Артефакт: текст SKILL.md, прочитанный против
   разделов спеки «Протокол deliver» и «Контракт акта». Ожидание:
   спека «Готово» 1, решения 1, 7. На базе падает: файла нет.
2. Состав 11 бандлов: массив `SKILLS` установщика, кортеж `SKILLS`
   `tests/test_install.py`, индекс `skills/README.md` несут deliver;
   паритет имён зелёный; usage установщика перечисляет deliver.
   Артефакт: вывод `pytest tests/test_install.py`, текст носителей.
   Ожидание: спека «Готово» 1. На базе падает: паритет 11 против 10.
3. Selfhost-порядок исполнен: после правки носителей —
   `scripts/install.sh .` (link), затем `--check` — `check: ok`;
   каталог скиллов сессии несёт deliver (каталог обновляется в сессии).
   Артефакт: вывод установщика (linked deliver), вывод --check,
   каталог скиллов. Ожидание: спека «Готово» 1, триаж G-26, G-15.
   На базе падает: deliver в каталоге и установке нет.
4. Шаблон блока init несёт строку команды поставки/обновления со
   ссылкой на скилл deliver; selfhost-блок репо равен шаблону
   (повторный init — diff пуст после); пины `tests/test_skill_init.py`
   (литерал блока, ENTRY_RULES) обновлены тем же срезом. Артефакт:
   текст шаблона, diff повторного init, вывод якорных тестов.
   Ожидание: спека «Готово» 2. На базе падает: пин строки блока
   отсутствует (мутация снятия строки краснит на новом дереве).
5. Красная проба критериев 1–4 финальным набором на базовом коммите
   `40c0dc6` — failed по существу критериев. Артефакт: красный лог.
   Ожидание: правило нарезки (критерии падают на базе).

## Ограничения

- Текст протокола — знание скилла; проектных фактов (абсолютных путей,
  имён сессий) в бандле нет.
- Правка блока init — только шаблон и пины; контракт владения init не
  усиливается до файловой эксклюзивности (триаж G-18).
- Живого исполнения протокола в тикете нет — проба тикета 03.
