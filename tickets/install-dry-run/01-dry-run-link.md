# 01: dry-run для link-режима

**Что построить:** `scripts/install.sh --dry-run <project>` в режиме link печатает
план установки — `would create`, `would link` или `would leave … unchanged` — и не
пишет на диск. Preflight выполняется: занятый не-симлинком путь даёт отказ с кодом
1, `--dry-run --check` — ошибку использования с кодом 2, а `--dry-run --copy` пока
отказывает с кодом 2: режим копии ставит тикет 02. Справка называет режим.

**Блокируется:** —

**Демо-путь:** запустить `--dry-run` на пустом временном проекте — увидеть семь
строк `would link` и отсутствие `.agents`; затем на установленном — семь `would
leave … unchanged` и неизменное дерево.

**Критерии приёмки** (каждый падает на базовом коммите `840520f`):

- [ ] `--dry-run <project>` на пустом проекте печатает `would create <dest>` и семь
      `would link <name> -> <src>`, выходит с кодом 0, `.agents` отсутствует
- [ ] на проекте с готовой установкой печатает семь `would leave <name> unchanged`,
      выходит с кодом 0, дерево не меняется
- [ ] при занятом не-симлинком пути печатает `refusing to replace`, выходит с кодом
      1 и не пишет ни одного скилла
- [ ] `--dry-run --check` выходит с кодом 2 и называет конфликт режимов
- [ ] `--dry-run --copy` выходит с кодом 2 и говорит, что режим копии не реализован
- [ ] `usage()` и шапка скрипта называют `--dry-run`

**Что я могу показать, когда это готово?** Два прогона `--dry-run` — на пустом и на
установленном проекте — с неизменным деревом в обоих случаях и отказом на занятом
пути.
