# 02: dry-run для copy-режима

**Что построить:** `scripts/install.sh --dry-run --copy <project>` печатает план
отсоединённой установки — `would copy` или `would leave … unchanged` — и не пишет на
диск. Разошедшаяся копия даёт отказ `copy differs` с кодом 1, как у реального
прогона.

**Блокируется:** 01 — там появляются режим, разбор флагов и временный отказ
`--dry-run --copy`; этот тикет отказ снимает.

**Демо-путь:** `--dry-run --copy` на пустом временном проекте — семь строк `would
copy` и отсутствие `.agents`; на отсоединённой установке — семь `would leave …
unchanged`.

**Критерии приёмки** (каждый падает на базовом коммите `840520f`):

- [ ] `--dry-run --copy` на пустом проекте печатает семь `would copy <name> ->
      <path>`, выходит с кодом 0, `.agents` отсутствует
- [ ] на готовой отсоединённой установке печатает семь `would leave <name>
      unchanged`, код 0, дерево не меняется
- [ ] при разошедшейся копии печатает `copy differs`, выходит с кодом 1 и не
      перезаписывает копию
- [ ] spec-тесты пунктов выше живут в `tests/test_install.py` рядом с контрактом
      установки

**Что я могу показать, когда это готово?** Два прогона `--dry-run --copy` — на
пустом и на отсоединённом проекте — с неизменным деревом и отказом на разошедшейся
копии.
