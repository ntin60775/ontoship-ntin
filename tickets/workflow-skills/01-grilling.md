# 01: скилл grilling

**Что построить:** `skills/grilling/SKILL.md` — носитель фазы 1 канона. Предмет
раскладывается в дерево дизайна; интервью идёт раундами по фронтиру: каждый раунд
задаёт весь фронтир, вопросы нумеруются, у каждого — рекомендованный ответ. Факты —
работа агента; решения — только оператора. Готово, когда фронтир пуст и оператор
подтвердил общее понимание. Выход — спека `docs/plans/<slug>.md` в форме
Цель / Готово / Рамки / Ограничения / Контекст и остановка на план-гейте.
Автономный режим назван вне рамок v1. Скилл вызывает модель.
