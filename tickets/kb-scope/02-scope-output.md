# 02: поле `scope` в `stat --json` и две строки при выборке путей

**Спека:** [docs/plans/kb-scope.md](../../docs/plans/kb-scope.md)

**Что построить:** вывод движка, механизм не трогается. `stat --json` несёт поле
`scope` (число исключённых файлов и число префиксов; нули, когда scope нет или
он пуст). `lint <paths>` по-прежнему считает `I4`, `I5` и глобальные проверки по
всему корпусу — контракт «пути сужают только per-file» остаётся в силе, — но итог
печатает двумя строками: `в выборке: <X> ERR · <Y> WARN` и
`вне выборки: <X′> ERR · <Y′> WARN`.

**Блокируется:** [01](01-scope-corpus.md) — без ридера scope печатать нечего.
**Предусловие:** решения 6, 7 и 17 спеки (ask и план-гейт 2026-11-10);
exit-коды 0/1/2 не меняются.

**Демо-путь:** фикстура с находкой внутри выборки и находкой вне её:
`gitmark.py lint docs/a.md` печатает обе строки, их суммы равны общему числу
находок, `checked` остаётся размером корпуса; `stat --json` показывает
`scope` с ненулевым числом исключённых; без path-аргументов второй пары строк
нет. Новые тесты краснеют на базовом коммите.

**Критерии приёмки**:

- [ ] поле `scope` — артефакт: вывод `gitmark.py stat --json` на фикстуре;
      ожидание: при ненулевом excludes JSON несёт `scope` с числом исключённых
      файлов и префиксов; без scope-файла — нули, поле на месте
      (спека «Готово» 7, решение 17)
- [ ] две строки при выборке — артефакт: stdout `lint <paths>` на фикстуре со
      смешанными находками; ожидание: строки `в выборке: <X> ERR · <Y> WARN` и
      `вне выборки: <X′> ERR · <Y′> WARN`, суммы равны общему числу находок,
      без path-аргументов пара строк отсутствует (спека «Готово» 5, решение 6)
- [ ] контракт сужения не тронут — артефакт:
      `tests/test_lint_paths.py`, тест `test_selection_narrows_only_per_file_checks`;
      ожидание: проходит без правки; `checked` остаётся размером корпуса;
      helper глобальных проверок не сужается (спека «Готово» 5, решение 6)
- [ ] exit-коды прежние — артефакт: коды трёх прогонов (чистый, ERR под
      `--strict`, отказ использования); ожидание: 0, 1, 2 — новых кодов нет
      (спека, решение 7)
