# 01: to-tickets вызывает агент

**Спека:** [docs/plans/to-tickets-agent.md](../../docs/plans/to-tickets-agent.md)

**Что построить:** замена фразы о вызове нарезки в каноне и его зеркале,
снятие флага и пользовательских формулировок со скилла, переворот
контрактного теста — одним срезом.

**Дословные тексты правки** (носитель держит дословно;
несовместимость «новый текст ↔ существующие пробы» — точка остановки,
решение оператора):

1. `docs/decisions/ontoship-core.md` и
   `skills/ship/references/method-phases.md` (синхронно):
   «`to-tickets` **вызывает пользователь**» → «`to-tickets`
   **вызывает агент**»; остальные предложения абзаца «Переходы»
   не меняются.
2. `skills/to-tickets/SKILL.md`, frontmatter: строка
   `disable-model-invocation: true` удаляется; description —
   «Скилл вызывает только пользователь.» → «Скилл вызывает агент.»
3. То же, тело: «Скилл вызывает пользователь; модель его не вызывает.
   Вызванный пользователем скилл может звать модельные скиллы
   (`kb-search`, `kb-curate`), но не другой пользовательский.» →
   «Скилл вызывает агент: нарезка идёт ask-проходом сразу после
   план-гейта.»
4. То же, «Когда использовать»: «Оператор позвал скилл после
   план-гейта и назвал спеку.» → «Фронтир пуст и спека утверждена на
   план-гейте: нарезка следует сразу.»; bullet «Не запускай
   самостоятельно: frontmatter несёт `disable-model-invocation:
   true`» удаляется.
5. `tests/test_skill_to_tickets.py`: якорь «вызывает пользователь» →
   «вызывает агент» (REQUIRED_PHRASES); frontmatter-проверка
   инвертируется — флаг должен отсутствовать (образец —
   `tests/test_skill_critic.py`, «disable-model-invocation must be
   absent»); мутационные пробы переворачиваются: вставка флага в
   frontmatter краснит, удаление якорной фразы краснит
   (case-insensitive, все вхождения). Точные фрагменты существующих
   проб читаются до правки — соседние якоря не рвать.

**Блокируется:** нет.

**Демо-путь:** полный набор `python3 -m pytest tests/ -q` зелёный
после среза; живая демонстрация контракта: временная вставка флага в
frontmatter скилла краснит, откат возвращает зелёный.

**Критерии приёмки**:

- [ ] канон — артефакт: `docs/decisions/ontoship-core.md`; ожидание:
      «`to-tickets` **вызывает агент**» в абзаце «Переходы»,
      `grep -c "вызывает пользователь"` по канону — 0 (спека,
      «Готово» 1)
- [ ] зеркало — артефакт: `skills/ship/references/method-phases.md`;
      ожидание: та же замена тем же текстом, `grep "вызывает агент"`
      находит в обоих носителях; якоря «Переходы ручные…» и «один
      прогон ревью…» на месте — наборы method-phases в
      `tests/test_canon_sync.py` зелёные (спека, «Готово» 2)
- [ ] скилл — артефакт: `skills/to-tickets/SKILL.md`; ожидание:
      frontmatter без `disable-model-invocation`, description
      «Скилл вызывает агент.», тело без «вызывает пользователь» и без
      правила «Вызванный пользователем скилл…», bullet «Не запускай
      самостоятельно» удалён, триггер агента в «Когда использовать»
      (спека, «Готово» 3)
- [ ] контракт — артефакт: `tests/test_skill_to_tickets.py`;
      ожидание: якорь «вызывает агент» в REQUIRED_PHRASES,
      frontmatter-проверка «disable-model-invocation must be absent»,
      мутации — вставка флага краснит, remove якорной фразы краснит;
      на базовом коммите краснеют только перевёрнутые и новые
      проверки — перечень упавших записан в этом тикете до реализации
      (спека, «Готово» 4)
- [ ] полный набор — артефакт: `python3 -m pytest tests/ -q` и
      `python3 skills/kb-search/gitmark.py lint --strict`; ожидание:
      зелёные после среза, паритет-наборы canon_sync и
      bundle_references не рваны (спека, «Готово» 5)
- [ ] индексы — артефакт: `docs/plans/README.md`,
      `tickets/README.md`; ожидание: `grep to-tickets-agent` находит
      запись в обоих (спека, «Готово» 6)
