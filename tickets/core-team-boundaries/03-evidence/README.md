## Разбор расхождений ожидание/факт

1. **mtime корня `.agents/skills` в copy-тесте.** Ожидание: дерево
   проекта байт-в-байт после установки. Факт: mtime каталога меняется
   при добавлении записей — легитимное следствие записи. Разбор:
   инвариант сверяет все предсуществующие записи кроме корня, чьи
   entries пополняются; комментарий в тесте. Не дефект установщика.
2. **Красная проба критерия 3 падала от предусловия (находка панели).**
   Ожидание: падение от отсутствия находки. Факт: первая версия теста
   на базе падала `FileExistsError` (базовый install сам ставит chain)
   и отказом preflight. Разбор: тест перестроен — запись нормализуется
   к засеянной форме; link-часть инварианта сеет чужой симлинк (база
   перепривязывает его — падение по существу); повторная красная проба
   подтверждает причины (`red-core.log`).
3. **Legacy-корни потеряли находку (находка панели, регрессия).**
   Ожидание: выведенный chain называется везде, где жил. Факт: база
   называла chain в `.dsh/.zcode/.qoder` перебором SKILLS; первая
   версия `retired_warnings` сканировала только `$dest`. Разбор:
   `retired_warnings` расширен на legacy-корни, тест
   `test_check_names_a_retired_bundle_in_legacy_roots`, краснота на
   базе — от отсутствия новой формулировки.

Иных расхождений не было.
