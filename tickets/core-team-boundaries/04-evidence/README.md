1. **Ошибка наблюдения драйвера (не пробы).** Драйвер (сессия
   тикета 04) принял работу reviewer-tests toy-панели за зависание:
   wait-цикл читал окно записей от старого курсора и не видел
   завершения. Факт по таймлайну сессии пробы: панель стартовала
   00:19:45, вердикт reviewer-tests доставлен 00:25:19 (~6 минут —
   штатная работа роли с независимым воспроизведением красноты),
   merge 00:26:59, финал 00:29:23. Попытка драйвера отменить вызов
   через API `session/cancel` отклонена (`session/not-found, not
   attached` — дочерние сессии не прикреплены к контроллеру
   оператора), побочных эффектов нет. Первая версия записи
   называла «~30 минут зависания» — цифра не подтверждена
   первичным логом, исправлена панелью.
2. **Опечатки артефактов у сессии пробы** (иероглифы вместо слова,
   транскрипт [231], [433]) — сессия сама заметила и исправила до
   коммита; исторический след в аргументах правок транскрипта
   сохранён; итоговые артефакты чисты.
3. **critic совпадает с моделью сессии** — стандартная раскладка
