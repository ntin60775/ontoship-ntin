1. **PR-путь не проверен: remote нет** (`git remote -v` пуст) — merge
   локальный, без фиктивного PR/CI.
2. **Гейт проекций**: записи триажа в `tickets/toy-readme/` нет; план-гейт,

   проход задан прямым решением оператора). Пропуск назван, не тихий.
3. **prod-проверки** спекой/тикетом не названы — деградация честная,
   демо-путь выполнен.
4. **Гейты пака: ноль** — паков нет (ожидаемо для голого ядра).
5. **P3-зацепки панели (4)** — в `tickets/toy-readme/hooks.md`: мёртвый
   якорь трассировки теста, newline теста, пустой runbook-скелет,
   отсутствие индекса `docs/ops/` (KB lint I5 WARN). Автоприёмку не блокируют.
6. **Init-файлы не закоммичены** (`AGENTS.md`, `.gitignore`,
   `.agents/config.toml`, `docs/ops/continue.md` — untracked): дизайн пробы
   их коммит не требует; названо как факт.
7. **`.scratch/` в gitignore, но артефакты пробы закоммичены** — прямое
   указание оператора (шаг 5 задания) выше правила блока; `git add -f`.
