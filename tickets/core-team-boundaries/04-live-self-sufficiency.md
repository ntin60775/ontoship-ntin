# Тикет 04 — Живая самодостаточность

Блокируется: 02, 03
Блокирует: 06

Спека: [core-team-boundaries.md](../../docs/plans/core-team-boundaries.md),
«Готово» 4. База нарезки: `88c8825`.

## Задумка

Одна изолированная сессия доказывает самодостаточность ядра по DoD
канона: чистый профиль без team, установка 10 бандлов, ручной ship
игрушечного тикета до main с зелёной панелью и таблицей гейтов.
Пробы team (mismatch/match, chain из бандла) сняты решением
оператора 2026-11-16 («тим тестировать не нужно») — названный пробел
до активации team.

## Демо-путь

Артефакты пробы в тикете: лог сессии, merge-коммит, отчёт панели,
таблица «гейт → доказательство → ответ оператора», вывод
plugin_manager (team нет), каталог скиллов (10, chain нет).

## Критерии приёмки

1. Изолированный хост: свежий DSH_HOME (или копия с выключенными
   ontoship-* строками), провайдеры и маршруты панели живы (факты
   среды — «Факты окружения» continue.md), чистая установка ядра —
   10 бандлов, init, каталог без chain. Артефакт: логи установки,
   plugin_manager, каталог. Ожидание: спека «Готово» 4, триаж G8.
   На базе падает: состав 11, chain в каталоге.
2. Профиль без team: вывод plugin_manager без ontoship-* бандлов.
   Пробы team (mismatch/match, chain из бандла) сняты решением
   оператора 2026-11-16 — названный пробел записан в артефактах
   пробы. Артефакт: лог plugin_manager + запись пробела. Ожидание:
   спека «Готово» 4 (ревизия 2026-11-16). На базе падает: team в
   профиле.
3. Ручной /ship заранее написанного игрушечного тикета (правка
   опечатки README temp-проекта; grilling и нарезка в пробу не
   входят) доходит до main; панель зелёная = нет открытых P1/P2,
   вердикты записаны; проба закрывает дифференциал юнита (каталог
   10 без chain, init-блок без chain-команд).
   Артефакт: merge + отчёт панели + дифференциал. Ожидание: спека
   «Готово» 4, триаж G8. На базе падает: дифференциал (состав,
   блок).
4. Таблица «гейт → доказательство → ответ оператора» записана в
   артефакты пробы. Артефакт: таблица. Ожидание: спека «Готово» 4
   («каждый гейт объясним»). На базе падает: таблицы нет.
