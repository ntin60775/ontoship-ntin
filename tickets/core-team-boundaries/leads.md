# Зацепки юнита core-team-boundaries

Реестр P3-находок и названных пробелов; автоприёмку не блокируют.

## Тикет 01 (панель 2026-11-16)

- **Цифровой снимок счётчика бандлов.** Лексемный скан снятого счётчика
  (артефакт критерия 4 спеки — grep «одиннадцать» = 0) не ловит «11
  бандлов» в четырёх носителях из пяти (harnesses прикрыт COUNTED_NOUN).
  Расширение на числовой скан по всем носителям не сделано намеренно:
  continue.md — хроника, числовой скан краснит легитимные исторические
  счета («все на 9 бандлах v0.6.0» consumer-registry). Возврат — решением
  оператора о более широком охранителе (панель: code P2, tests P3-1,
  spec P3-3; закрыто сужением заявки до артефакта спеки).

## Тикет 02 (панель 2026-11-16)

- **Указатель стартового промпта актору.** Правило генерации живёт
  только в chain-скилле team-бандла; тикет 03 снимает шаг to-tickets
  и «орк-промт». Носитель указателя «загрузи chain» для сессии
  планирования (init-блок / AGENTS.md / персона) назвать в тикете 03
  (панель code P3).
- **tool-todo orchestrator не пиннится тестом.** Существующий тест
  композиции проверяет tool-schedule, todo_write не asserted;
  G13-регресс пройдёт зелёным. Новые тесты team не пишутся (решение
  оператора) — пробел до юнита ведения (панель spec P3).
- **Живая проверка коннектора.** Каталог chain из пина, mismatch
  (v0.2.1), match (объявление 3) сняты решением оператора
  2026-11-16 — пробел до активации team; самодостаточность ядра
  без team доказывает тикет 04.
- **Исторические цитаты в docstring team-тестов.** «эталон — релиз
  метода» в contract.spec/manifest.spec — цитата спеки team-profiles
  (трассируемость), перекрыта маркером core-team-boundaries 02;
  сохранена намеренно (панель kb/tests/spec P3).

  костылей; формулировка «Готово» 5 ревизована (аннотация 2026-11-17

## Тикет 06 (панель и пробы 2026-11-17)

- **pytest main собирает тесты вложенных worktree.** Факт среды
  (проба релиза, не панель): `pytest.ini` несёт
  `norecursedirs = vendor .scratch`, переопределяя умолчание с `.*`;
  при живом worktree в `.agents/worktrees/*` pytest main собирает
  его тесты и краснит import mismatch (29 errors). Обход практики:
  набор main гоняется после сноса worktree (тикеты 05/06).
  Кандидат: добавить `.agents` (или `worktrees`) в norecursedirs
  pytest.ini — правка инварианта сборки, отдельным решением;
  место: pytest.ini, скилл ship (порядок проб).
