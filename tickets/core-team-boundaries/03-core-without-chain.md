# Тикет 03 — Ядро без chain

Блокируется: 02
Блокирует: 04

Спека: [core-team-boundaries.md](../../docs/plans/core-team-boundaries.md),
«Готово» 3. База нарезки: `88c8825`.

## Задумка

Установщик метода больше не поставляет chain (10 бандлов), словарь
ведения уходит из скиллов метода, установщик только сообщает о
выведенном бандле, инвариантный тест сторожит отсутствие
team-литералов в скиллах ядра.

## Демо-путь

`install.sh --check` на temp-проекте с установленным chain печатает
находку «chain выведен — удали вручную»; инвариантный тест зелёный;
каталог скиллов свежей сессии — 10 бандлов без chain.

## Критерии приёмки

1. Массив SKILLS — 10 бандлов, skills/chain/ снят, skills/README.md
   и кортеж tests/test_install.py в паритет. Артефакт: install.sh +
   вывод --check + паритетный тест. Ожидание: спека «Готово» 3.
   На базе падает: состав 11.
2. to-tickets без шага «Передача в цепочку» и команды «орк-промт»;
   контекстные строки ship о драйвере сняты; блок init — команды
   ядра, ссылка team в §5/отчёте (пакет и версия, без литералов
   маршрутов, бандла нет — шаг молчит); скелет continue.md в init и
   «Правила продолжения» правятся. Артефакт: тексты скиллов +
   контрактные тесты. Ожидание: решение 3, триаж G4. На базе падает:
   шаг и команды присутствуют.
3. Установщик: находка --check о выведенном бандле по образцу
   legacy_warnings; delete-пути нет, запись только под .agents —
   инвариант канала сохраняется. Артефакт: вывод --check на temp с
   chain + инвариантный тест установки. Ожидание: триаж G10/S3.
   На базе падает: находки нет.
4. Инвариантный тест: область — skills/**/SKILL.md,
   skills/*/references/*.md, массив SKILLS; литералы — session_read,
   ontoshipExecutors, allowedAgentPresets, id пресетов команды;
   справочник dsh-preset-allowlist.md переезжает в team. Артефакт:
   тест + дерево. Ожидание: триаж G11. На базе падает: литералы в
   skills/chain присутствуют.
5. Selfhost: симлинк .agents/skills/chain снят вручную с записью.
   Артефакт: ls .agents/skills + запись в тикете. Ожидание: спека
   «Готово» 3. На базе падает: симлинк присутствует.
