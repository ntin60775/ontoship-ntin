# Ишью 10 — установщик сносит реальные legacy-каталоги (архив → снос)

Источник: зацепка панели nf08 и проба пробелов 2026-11-25; решения
оператора: «делай тикет», «тоже сносить при поставке бандла если есть».
Ревизия границы nf08 («реальные каталоги не трогаются») прямым решением
оператора.

Блокеры: нет.

## Решение

Install-режимы (link/copy) сносят реальные каталоги бандлов ядра в
legacy-корнях (`.dsh/skills/<name>`, `.zcode/...`, `.qoder/...`):
сначала архив каталога в `~/.dsh/state/ontoship/legacy-archive/`
(персистентно, вне проекта), затем снос, печать `removed legacy copy
... (archived: ...)`. Архив сохраняет возможные локальные знания
(форк); миграция из архива — отдельным проходом решением оператора.
Без архива снос не делается: отказ архивации — именованный отказ,
каталог не тронут. `--check` называет реальные legacy-копии warning'ом
(«the next install removes it (archived)»), exit не ломает.
Симлинк-корни и симлинк-base наружу не разыменовываются (guard nf08).
`--dry-run` печатает план без записи. `--pack` legacy не трогает.

## Критерии приёмки

1. **Install сносит реальную legacy-копию с архивом.** Артефакт: вывод
   install (link и copy) на проекте с реальным `.dsh/skills/kb-search/`
   (файл внутри). Ожидание: `removed legacy copy`, каталога нет, архив
   содержит файл байт-в-байт.
2. **Форк переживает снос в архиве.** Артефакт: legacy-копия с локальным
   файлом, отличным от продюсера. Ожидание: файл в архиве, знание не
   потеряно.
3. **Check называет, install-режимы сносят, dry-run не пишет.**
   Артефакт: вывод --check / --dry-run, дерево до/после. Ожидание:
   warning назван; dry-run — `would remove legacy copy`, дерево цело.
4. **Внешняя граница цела.** Артефакт: target-тест nf08 (симлинк-корень
   и симлинк-base во внешний каталог). Ожидание: зелёный, внешние
   каталоги целы.
5. **Красная проба на базе.** Артефакт: прогон новых тестов на базовом
   коммите. Ожидание: падают.
6. **Носители нормы.** Артефакт: install.sh (шапка/usage/комментарии),
   `skills/deliver/SKILL.md` шаги 3/5, пины `tests/test_skill_deliver.py`,
   приписка `docs/plans/harness-agnostic.md`, ревизия
   `docs/plans/deliver.md`, `docs/reference/harnesses.md`. Ожидание:
   одна норма, прежние формулировки сняты.
7. **Набор зелёный.** Артефакт: pytest + `lint --strict`. Ожидание:
   0 failed, lint чисто.

## Демо-путь

Temp-проект: реальный `.dsh/skills/kb-search/` с локальным файлом →
`--check` warning → install → `removed legacy copy (archived: ...)` →
каталога нет, файл в архиве → `--check` без warning.
