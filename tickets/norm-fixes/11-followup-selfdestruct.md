# Ишью 11 — followups самоуничтожаются при выполнении

Источник: проба пробелов 2026-11-25, зацепка «28 открытых followups»;
решение оператора: «вообще убить хвосты. напоминание должно
самоубиваться когда выполнено».

Блокеры: нет.

## Решение

Правило 3 скилла `consumer-registry` ревизовано: выполненный followup
удаляется из записи `deploy_log` (самоуничтожение), а не помечается
флагом; открытые остаются до выполнения. `deploy_log` append-only
по записям; followups внутри записи — рабочие напоминания, не история.
Поле `done` оставлено для чтения старых реестров; записи с `done: true`
подлежат удалению при ближайшей правке. Схема `consumer-registry/1`
не меняется (поле остаётся, поведение — правило скилла).
