# Ишью 03 — copy-канал пака несёт `.git` источника

Источник: репетиция юнита `org-regulations-delivery` (репо 1C-DSH), отчёт
`tickets/org-regulations-delivery/evidence/T5-rehearsal-report.md`.
`install_pack_copy` копировал каталог источника целиком (`cp -a`,
исключения — только `__pycache__`/`*.pyc`), `is_copy_of` сравнивал
включая `.git`.

Следствия: в копии пака у потребителя жил git-история орг-репо
(вложенный репозиторий в `.agents/packs/<name>/`), а любое изменение
`.git` источника — пустой коммит, обновление index — давало ложный отказ
`copy differs` при неизменном контенте норм.

Правка (решение оператора 2026-11-22 «да», вне тикетного потока, как
ишью 01/02): `.git` входит в `EXCLUDES` — `is_copy_of` сравнивает
контент пака; свежая копия снимает `.git` при установке (на любой
глубине, ровно как исключение в сравнении). Установщик не удаляет `.git`
в уже существующей копии: снос чужого репозитория — действие оператора,
не установщика.

Приёмка: два target-теста краснеют на базе `e55e8c9`; регрессионный тест
перехода link→copy краснеет и на промежуточной правке, где снятие `.git`
шло через симлинк и уничтожало репозиторий источника. Набор зелёный,
lint --strict чист, selfhost `check: ok`.


## Исполнение и приёмка (2026-11-22, решение оператора, вне тикетного потока)

`scripts/install.sh`: `EXCLUDES` несёт `-x .git`; `install_pack_copy`
после `cp -a` снимает `.git` (`find "$target" -name .git -prune`),
рядом с уборкой байткода; `plan_pack` не менялся — обещание «would copy»
истинно и без отдельной строки про `.git`.

`tests/test_pack_channel.py`:
`test_pack_copy_carries_content_not_source_git` — dry-run не пишет,
копия без `.git`, пустой коммит в источнике → exit 0 и «unchanged»;
`test_pack_copy_from_link_keeps_source_git` — переход link→copy: у копии
`.git` нет, у источника цел (`git rev-parse` после прогона). Ожидание —
из ишью, не из кода установщика.

Доказательства: база `e55e8c9` — оба теста красные; промежуточная правка
`04910bc` (heal через `rm -rf` до проверки симлинка) — link→copy красный,
`.git` источника уничтожен; срез — 16 passed в файле, набор **812
passed**, lint --strict чисто, selfhost `install.sh --check .` — `check: ok`.

Названный пробел: копии, поставленные до фикса, сохраняют `.git`
источника; установщик их не трогает (удаление чужого репозитория не его
решение). Лечится ручным сносом копии; `--copy --pack` после этого
поставит чистую. Ишью закрыт.
