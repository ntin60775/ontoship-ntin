# 02: init — третий файл и бутстрап-выбор моделей

**Спека:** [docs/plans/review-config.md](../../docs/plans/review-config.md)

**Что построить:** init создаёт `.agents/config.toml`: при отсутствии конфига
спрашивает модели ролей ядра (пять) ask-инструментом из активных моделей хоста,
запускает генерацию определений; при повторном прогоне конфиг не трогает.
Совпадение выбранной модели критика с сессионной — отказ с объяснением. Новая
роль ядра при существующем конфиге — называет пропуск, предлагает добавить,
молча не дописывает. init пишет ровно три файла: `AGENTS.md`, `.gitignore`,
`.agents/config.toml`. Нет источника моделей — названный пробел и остановка.

**Блокируется:** 01 — схема конфига и генератор появляются там.

**Демо-путь:** пустой временный проект → init → конфиг с ролями и определения;
повторный прогон → `git diff` пуст; выбор модели критика, равной сессионной, →
отказ с объяснением.

**Критерии приёмки** (каждый падает на базовом коммите `0b54a62`):

- [x] init без конфига спрашивает модели ролей ask-ом, пишет конфиг и
      запускает генерацию определений
- [x] модель критика, совпадающая с сессионной, — отказ с объяснением
- [x] повторный прогон при существующем конфиге ничего не меняет; новая роль
      ядра при существующем конфиге — названный пропуск, без молчаливой дописки
- [x] init пишет ровно три файла — `AGENTS.md`, `.gitignore`,
      `.agents/config.toml`; без источника моделей останавливается с пробелом
- [x] spec-тесты пунктов выше в `tests/` падают на базе
