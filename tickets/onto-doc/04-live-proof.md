# 04: живое доказательство — полный онто-док прогон

**Спека:** [docs/plans/onto-doc.md](../../docs/plans/onto-doc.md)

**Что построить:** выделенный git worktree от текущего master; survey
репозитория и декомпозиция на док-области — в сессии (решение 7); запуск
прогона онто-док — кураторы workflow-транспортом на модели из
`[agents.curator]`; после прогона — `lint --strict` зелёный, индекс и карта
регенерированы; diff — оператору, коммит — оператора; worktree убирается
после разбора (решение 10).

**Блокируется:** 02

**Демо-путь:** карточка dwfrun-прогона и вывод `lint --strict` в тикете;
diff работы кураторов — оператору.

**Критерии приёмки**:

- [ ] прогон состоялся на конфиговой модели — артефакт: карточка dwfrun-прогона
      (модель субагентов `account:zai-individual-coding-plan/GLM-5.3-Flash$max`
      из `[agents.curator]`); ожидание: кураторы отработали по своим кускам,
      отказов куска нет или каждый разобран
- [ ] гейт зелёный в worktree — артефакт: вывод
      `python3 .agents/skills/kb-search/gitmark.py lint --strict` в worktree
      после прогона; ожидание: `✓ чисто`, индекс пересобран, карта
      сгенерирована
- [ ] diff прочитан оператором — артефакт: решение оператора в тикете
      (принять diff / править / откатить worktree); ожидание: коммит делает
      оператор, не прогон
- [ ] разбор расхождений ожидание/факт — строка «не было» или разбор
      ([testing.md](../../docs/reference/testing.md))
