# 02: скилл и прогон — онто-док из оригинала

**Спека:** [docs/plans/onto-doc.md](../../docs/plans/onto-doc.md)

**Что построить:** `skills/onto-doc/SKILL.md` — перевод шагов 1–6 и принципа
оригинального `/onto-doc` (клон `contrib/clones/ontoship`,
`commands/onto-doc.md`), адаптации — только списком решения 2 спеки:
команда → скилл; `Task` → кураторы workflow-транспортом с `subagent_model`
из `[agents.curator]`; путь движка — `skills/kb-search/gitmark.py`;
подсказка области `$ARGUMENTS` убрана — область приходит из разговора; шаг
«ensure CLAUDE.md/AGENTS.md» — проверка и отчёт, запись — домен init;
описание несёт триггеры («онто-док», «погони онто-док», «бутстрап KB»,
«пересбор KB») и границу с `kb-curate`. Процедура запуска в скилле: сверка
`model`+`level` роли куратора с ListModels — расхождение стоп, нет каталога —
названный пробел и стоп (решение 4); чтение отчёта прогона; lint и index
и map — в сессии. Сохранённый workflow `.zcode/workflows/onto-doc.dwf.ts`
с аргументами `root` (корень KB — worktree прогона) и `plan` (куски
декомпозиции `[{path, what}]`, по куратору на кусок; решение 8); файл печатает
назначенную модель в log и не несёт плейсхолдеров. Сверка `ship` расширяется
с модели до модели и уровня (решение 4; якорь в `tests/test_skill_ship.py`).
Строка онто-дока в матрице `docs/reference/harnesses.md`. Девятый бандл —
три носителя: `scripts/install.sh`, строка usage `--check`, контракт
`tests/test_install.py`.

**Блокируется:** 01

**Демо-путь:** файл workflow с аргументами `root`/`plan` в репо;
`scripts/install.sh "$PWD" && scripts/install.sh --check "$PWD"` — девять
бандлов; контрактные тесты зелёные после правки.
