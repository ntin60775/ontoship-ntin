# 05: живое доказательство — полный онто-док прогон

**Спека:** [docs/plans/onto-doc.md](../../docs/plans/onto-doc.md)

**Что построить:** выделенный git worktree от текущего master; движок
в worktree — `scripts/install.sh <worktree>` до прогона либо отслеживаемый
путь: `python3 skills/kb-search/gitmark.py --root <worktree> …` —
`.agents/skills/` в свежем worktree нет, он в `.gitignore`; сессия прогона —
в чекауте с закоммиченным workflow, `args.root` — worktree, подтверждение
запуска — оператора; survey и декомпозиция — в сессии (решение 7); запуск —
кураторы workflow-транспортом на модели из `[agents.curator]`; карточка
прогона несёт список областей и строку на область (куратор, записанные
файлы, отказ) и назначенную модель из log прогона; после — `lint --strict`
зелёный в worktree, индекс и карта регенерированы; оператору —
`git diff --stat` и выборочные куски, `*-map.html` из diff исключён;
коммит — оператора; worktree убирается после разбора (решение 10).

**Блокируется:** 02

**Демо-путь:** карточка dwfrun-прогона, вывод `lint --strict` и
`git diff --stat` в тикете.

**Критерии приёмки**:

- [ ] прогон на конфиговой модели — артефакт: карточка dwfrun-прогона
      и строка log прогона с назначенной моделью; ожидание: модель — из
      `[agents.curator]` (решения 3–5), не из сессии и не угаданная
- [ ] области видимы — артефакт: список областей в карточке и строка
      на область: куратор, записанные файлы, отказ; ожидание: декомпозиция
      сессии покрыта кусками, отказы разобраны (решение 7)
- [ ] гейт зелёный в worktree — артефакт: вывод `lint --strict` в worktree
      (движок установлен `install.sh` либо вызван с `--root`) и
      пересобранный индекс; ожидание: `✓ чисто`, карта сгенерирована
- [ ] diff прочитан оператором — артефакт: решение оператора в тикете
      (принять diff / править / откатить worktree); оператору показаны
      `git diff --stat` и выборочные куски, `*-map.html` в diff не входит;
      коммит делает оператор
- [ ] разбор расхождений ожидание/факт — строка «не было» или разбор
      ([testing.md](../../docs/reference/testing.md))
