# 01: конфиг и генератор — куратор и уровни

**Спека:** [docs/plans/onto-doc.md](../../docs/plans/onto-doc.md)

**Что построить:** секция `[agents.curator]` в `.agents/config.toml` —
`model = "account:zai-individual-coding-plan/GLM-5.3-Flash"`,
`level = "max"` (решения 3 и 4); ключ `level` добавляется во все шесть секций
реестра; `skills/init/gen_agents.py` принимает необязательный ключ `level` и
пишет `thoughtLevel` в определение роли, у роли без ключа — строку опускает
(решение 6); семантика: пустая строка `level` — именованный отказ, незнакомое
значение проходит до сверки при запуске; предупреждение о незнакомых ключах
и именованные отказы невалидного остаются.

**Демо-путь:** прогон `python3 skills/init/gen_agents.py <корень>` печатает
`6 role(s) in sync`; `.zcode/agents/curator.md` несёт `model` и
`thoughtLevel: max` (каталог gitignored — показать файл с диска).

**Критерии приёмки**:

- [x] генератор понимает `level` — артефакт: лог
      pytest tests/test_gen_agents.py -q: новое утверждение против
      генератора базового коммита красное по отсутствию поддержки ключа,
      после правки зелёное; ожидание: `level` в конфиге даёт `thoughtLevel`
      в render, роль без `level` остаётся без строки (решение 6); мутации:
      удаление `thoughtLevel` из render и молчаливое принятие пустого
      `level` — каждая краснит
- [x] реестр несёт шесть секций с уровнями — артефакт: вывод генератора на
      живом конфиге и шесть файлов `.zcode/agents/*.md` с

- [x] контрактный слой не тронут — артефакт: полный прогон

**Доказательства (исполнитель, до merge):**

- Критерий 1, красный против базового генератора (тесты добавлены,
  генератор и конфиг ещё не правлены): `6 failed, 24 passed` — падают
  `test_level_yields_thoughtlevel_and_absence_omits_it`,
  `test_unknown_level_value_passes_through` и четыре параметра
  `test_invalid_level_fails_with_named_error`; причина каждой — отсутствие
  поддержки ключа: `unknown key 'level' ignored`, строки `thoughtLevel` в
  определении нет, отказа на пустом значении нет. Две мутационные пробы на
  базе зелёные — мутировать нечего.
- Критерий 1, зелёный после правки: `30 passed` в файле. Мутации на боевом
  коде, каждая краснит: удаление `thoughtLevel` из render — `2 failed`
  (тест thoughtLevel/отсутствия и тест прохода незнакомого значения);
  молчаливое принятие пустого `level` (`if False:` вместо проверки) —
  `4 failed` (все параметры именованного отказа). Код восстановлен

**Разбор расхождений ожидание/факт:** (1) Тикет называет именованным
отказом только пустую строку `level`; факт — отказ ещё и на не-строке
(`level = 5`, `true`): общее правило генератора «невалидное — именованный
отказ» распространено на значение ключа, как у `model` (критерий 1: отказы
невалидного остаются). Тест — четыре параметра. (2) Остальное без
расхождений: краснота и зелень совпали с ожиданием, набор вырос ровно на
восемь тестов, все шесть секций несут `level = "max"` — обе модели реестра
по пробам спеки несут `levels: high, max`, максимум `max`.
