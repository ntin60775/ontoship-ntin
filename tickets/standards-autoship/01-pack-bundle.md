# 01: Бандл pack — контракт, валидатор, эталонный пак

**Спека:** [standards-autoship](../../docs/plans/standards-autoship.md),
«Готово» 1; решения 2, 3, 6, 7.

**Блокируется:** ничем.

**Что построить:** новый бандл ядра `pack` — скилл `pack` (модельный:
контракт пака, валидация, настройка базовых стандартов; шаг базовых
стандартов — тикет 03), API-документ контракта в `references/` (схема
манифеста: тип команда/стек, версия, роли, стандарты, гейты; форматы
стандартов, чек-листов ролей `reviewer-<kontur>-<aspect>` и конфигов
механических гейтов как данных), валидатор на stdlib и эталонный
минимальный пак. Массив `SKILLS` установщика и паритет перечня бандлов
расширяются одним именем; состав бандлов становится десять до тикета 06.

**Демо-путь:** валидатор на эталонном паке и на сломанном манифесте.

```console
$ python3 skills/pack/<валидатор> <эталонный пак>
$ python3 skills/pack/<валидатор> <пак со сломанным манифестом>
```

ожидание: эталон проходит (exit 0), сломанный манифест отвергается
именованным отказом (exit не 0, причина в stderr). Сегодня: валидатора
нет, команда не существует.

**Критерии приёмки**:

- [x] Бандл существует и ставится — артефакт: файлы `skills/pack/`
      (SKILL.md, references/, валидатор, эталонный пак), вывод
      `install.sh --copy` в temp и `--check`; ожидание: бандл доезжает
      целиком, `check: ok`; на базе бандла нет.
- [x] Контрактные тесты API и валидатора — артефакт: новый набор в
      `tests/`, прогон на базовом коммите и на срезе; ожидание: красная
      проба на базе (набора нет / носители отсутствуют), зелёный набор
      на срезе; тесты доказывают пункты контракта (схема манифеста,
      форматы, именование ролей), а не пересказ реализации.
- [x] Валидатор умеет падать — артефакт: вывод демо-пути на эталоне и
      на мутациях манифеста (убранное поле, чужой тип, неизвестный ключ);
      ожидание: эталон проходит, каждая мутация отвергается именованным
      отказом; негативная матрица приложена к набору.
- [x] Паритет перечня бандлов — артефакт: прогон существующего теста
      паритета `SKILLS`; ожидание: перечень из десяти бандлов совпадает
      по всем носителям, мутация (убранное имя) краснит.

## Доказательства

**Набор.** Полный набор на срезе после правок панели — **568 passed**
(база 519 + 49 новых: `tests/test_skill_pack.py` — 6,
`tests/test_pack_validator.py` — 43). `lint --strict` — `✓ чисто`
(53 файла). Copy-установка в `/tmp/sas01-install2`: `copied pack`,
все файлы бандла на месте, `check: ok` (десять бандлов).

**Красная проба на базе.** База `de5e9d2`, временный worktree, новые
тесты поднесены к базе: **49 failed / 0 passed** — носители бандла
`skills/pack/` на базе отсутствуют. Прогон панели reviewer-tests
независимо подтвердил красноту (54 failed / 14 passed с учётом
кортежа `test_install.py`).

**Демо-путь.**

```console
$ python3 skills/pack/validate_pack.py skills/pack/reference-pack
✓ пак reference-pack (team, 1.0.0) валиден        # exit 0
$ python3 skills/pack/validate_pack.py <сломанный манифест: type=contour>
pack: манифест: type — team или stack: 'contour'  # stderr, exit 2, stdout пуст
```

Негативная матрица — 32 мутации контракта (схема, пути, роли, гейты,
юникод-цифры версии, симлинк наружу, нечитаемый манифест, ANSI-инъекция
в stderr), каждая — именованный отказ exit 2 с пустым stdout; позитивы:
эталон, минимальный манифест без optional-ключей, гейт без expect_exit.
C-локаль (`LC_ALL=C`, `PYTHONUTF8=0`, `PYTHONIOENCODING` снят): вывод
UTF-8, без трейсбека.

**Панель.** Четыре роли на `qwen-token-plan/qwen3.8-flash` (`xhigh`,
маршрут сверен с живым каталогом), один прогон, вход артефактный:
reviewer-spec — «принять с находками» (1 P2 / 4 P3), reviewer-tests —
«принять с находками» (1 P1 / 1 P2 / 4 P3), reviewer-code — «принять с
находками» (2 P2 / 9 P3), reviewer-kb — «принять с находками» (5 P3).
27 сырых находок, 21 после дедупликации, 20 закрыты одним проходом
правок: доказательства в тикете (P1), морфология преамбулы контракта,
два выживших мутанта (гейт `name=""`, не-строка в standards) + позитив
expect_exit, redact недоверенного текста отказов (`!r` + замена
управляющих, идиома gitmark), сила C-локального теста (pop
`PYTHONIOENCODING`, timeout), forward-ссылки на канал `--pack`/init
переписаны как названный пробел, fail-fast формулировка, OSError чтения
манифеста, симлинк-контейнмент (`resolve` + `is_relative_to`),
юникод-цифры версии (`[0-9]`), идиома UTF-8-гарда с докстрингом,
завершающие переводы строк, мёртвый `*extra`, точность отказов
(«ожидается каталог», regex в сообщении name), полный usage-контур в
тесте, фрагменты мутаций — литералы контракта, can-fail через предикат
по мутированному носителю, harness-root скан всех файлов бандла,
ширина прозы и метка ссылки контракта, строка pack в корневом README.

**Зацепка оператору (не закрыта, решение оператора):** репо-трассировка
в поставляемом коде — `spec:`/`invariant:` в докстринге
`validate_pack.py` адресуют `docs/plans/` этого репозитория; в чужом
проекте адреса не существуют. Рекомендация: сохранить (провенанс
знания, трассировка каноном не правится); альтернатива — трассировка
только в тестах. Решение — при приёмке или отдельным ask.

**Заметки без приоритета:** «девять бандлов» в continue.md — датированная
хроника (жанровое исключение), не правится; «Когда использовать» pack
во 2-м лице единственного числа — канон не нарушен, заметка о жанре.
