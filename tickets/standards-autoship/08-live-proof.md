# 08: Живая проба полного потока и закрывающий набор

**Спека:** [standards-autoship](../../docs/plans/standards-autoship.md),
«Готово» 12, 14; решение 18.

**Блокируется:** тикеты 01–07, 09.

**Что построить:** живая проба полного потока в temp-проекте: установка
ядра и эталонного пака каналом `--pack`, init с паком, утверждение
базовых стандартов, игрушечный юнит — grilling → спека → план-гейт →
проекции с триажем → нарезка с самопроверкой → чистая сессия
оркестратора → цепочка → сессия-исполнитель → панель с ролью пака →
механические гейты пака → автоприёмка тикета → merge → финишная приёмка
с отчётом и диаграммами. Закрывающий полный набор тестов, `lint
--strict`, `install.sh --check`. Живой 1С-пак — названный пробел до его
создания; страж бюджета по оценке — названный пробел счётчика.

**Демо-путь:** сквозной прогон игрушечного юнита в temp-проекте.

ожидание: артефакты пробы (идентификаторы сессий и прогонов, коммиты,
отчёты с mermaid-диаграммами) записаны в этот тикет; игрушечный юнит
прошёл весь поток без ручного чтения кода оператором; оператор
участвовал только в план-гейте, нарезке и финишной приёмке. Сегодня:
поток не существует, прогон невозможен.

**Критерии приёмки**:

- [ ] Сквозной прогон — артефакт: идентификаторы сессий (планирование,
      проекции, оркестратор, исполнитель, панель), коммиты игрушечного
      юнита, отчёт триажа, записи автоприёмки, финальный отчёт с
      диаграммами; ожидание: каждый этап потока назван и доказан,
      пробелы названы пробелами; на базе прогон невозможен.
- [ ] Ручные гейты оператора — артефакт: записи ask-проходов пробы
      (план-гейт, нарезка, финишная приёмка); ожидание: других ручных
      гейтов в пробе нет, автоприёмка тикета прошла без ask.
- [ ] Закрывающий набор — артефакт: вывод полного набора тестов,
      `lint --strict`, `install.sh --check`; ожидание: полный набор
      зелёный (цифра названа), линт чист, `check: ok`; красные пробы
      новых наборов на базовом коммите названы в тикетах 01–07, 09.
