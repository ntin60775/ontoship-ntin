## Что делает

Значения конфига не меняются (это тикет 02); тесты становятся
потребителями конфига.

- `tests/test_role_registry.py`:
  - конфиг читается `tomllib`; уходят `STANDARD_POOL`, `CHAIR_ROUTE` и
    все литералы пар пула;
  - инвариант: пул — три записи, три различных model-части; у каждой
    роли из `CORE_ROLES` (`roles.py`) есть секция с маршрутом
    `provider/model`; у каждой записи пула непустой `level` (level роли
    может отсутствовать — дефолт модели); `[agents.critic]` несёт
    маршрут, значение читается из конфига;
  - мутации строятся из значений, прочитанных из конфига: дубль первой
    записи пула, пул без последней записи, `level = ""` у записи пула,
    удаление секции `[agents.<role>]` роли, взятой из `CORE_ROLES`, —
    красные;
  - действующие пробы `no-pool-section`, `lost-level`, `duplicate-entry`,
    `same-model-twice`, `lost-core-section` остаются, needle — из
    разобранного конфига; `drifted-route` и `chair-route` сняты — смена
    структурно валидного значения законна (живость — runtime);
  - зелёная проба: model-часть первой записи пула → `model-probe`
    (провайдер тот же, различность цела) — `_config_errors` пуст; на
    базовой ревизии та же правка красная;
  - паритет config↔init по инварианту: `_init_pool_errors` требует от
    init те же три части структуры (три различных модели по model-части,
    ask из живого каталога, запись после ответа), а не пары;
    `test_init_pool_parity_can_fail` краснит потерей структуры.
- `tests/test_skill_critic.py`: `POOL_MODELS` из конфига; структурная
  проверка пула (непустой, model-части различны) с падающими пробами —
  пустой пул и дубль; `test_skill_hardcodes_no_pool_route` с падающей
  пробой — всаженный в текст скилла маршрут из конфига краснит.
- `skills/init/SKILL.md`: абзац пула — структура (три различных модели
  по model-части) + ask на бутстрапе (варианты из живого каталога,
  запись после ответа; делегированный прогон — названный стоп); правило
  «пиши без ask» из пула уходит; пар пула нет; раскладка шести ролей не
  меняется.
- `tests/test_skill_init.py`: `POOL_NEEDLES` — структурные фразы вместо
  пар; `test_pool_contract_can_fail` — мутации по структуре;
  `LAYOUT_NEEDLES` и пробы раскладки остаются.
- `docs/plans/critic-consilium.md`: приписка — инвариант, пары пула —
  конфиг, паритет по инварианту.
