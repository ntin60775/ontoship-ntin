# Тикет 01 — тесты-потребители и init bootstrap структуры

Юнит: registry-source. Спека: [docs/plans/registry-source.md](../../docs/plans/registry-source.md).
Блокеры: нет (базовый коммит).

## Демо-путь

`pytest tests/ -q` зелёный; структурные мутации (дубль модели, неполный
пул, потеря роли) красные; зелёная проба структурно-различной замены
маршрута зелена. Показываю: вывод pytest и мутационные пробы.

## Что делает

Тесты становятся потребителями конфига (значения ещё не меняются):

- `tests/test_role_registry.py`: читает конфиг через `tomllib`;
  структурный инвариант — пул из трёх записей, три различных модели
  (по model-части `provider/model`), роли ядра и critic на месте,
  уровень непустой. Литералы `STANDARD_POOL` и `CHAIR_ROUTE` убраны
  (chair читается из конфига). Мутации структурные: дубль модели,
  неполный пул, потеря роли — красные; замена валидного маршрута на
  структурно-различный — зелёная.
- `tests/test_skill_critic.py`: `POOL_MODELS` читается из конфига,
  падающая проба (пустой пул / дубль модели).
- `skills/init/SKILL.md`: пул — структура (3 различных модели) + выбор
  маршрутов на бутстрапе из живого каталога, без хардкода маршрутов;
  `tests/test_skill_init.py` обновлён под структуру init (не литералы).
- `docs/plans/critic-consilium.md`: приписка — инвариант «3 различных
  модели», маршруты — выбор конфига; хардкод маршрутов и «паритет с
  init» по значениям сняты, паритет по инварианту.

## Критерии приёмки

- Зелёная проба single-source: замена валидного маршрута в конфиге на
  структурно-различный не краснит `test_role_registry`. Артефакт:
  вывод pytest. Ожидание: на базе красная (хардкод `STANDARD_POOL`
  ловит смену), после правки зелёная (инвариант цел).
- Структурные мутации: дубль модели пула, неполный пул, потеря роли
  ядра — красные. Артефакт: мутационные пробы. Ожидание: нарушение
  инварианта краснит.
- `CHAIR_ROUTE` читается из конфига, литерал отсутствует. Артефакт:
  grep теста, вывод pytest. Ожидание: литерала нет, chair из конфига.
- `test_skill_critic` `POOL_MODELS` из конфига + падающая проба
  (пустой/дубль). Артефакт: вывод pytest. Ожидание: проба краснит на
  нарушении.
- init-скилл несёт структуру + выбор, без хардкода маршрутов;
  `test_skill_init` проверяет структуру. Артефакт: текст init, вывод
  pytest. Ожидание: литералов маршрутов пула в init нет, структура
  названа.
- Приписка critic-consilium: инвариант, паритет по инварианту.
  Артефакт: файл. Ожидание: хардкод маршрутов снят.
- `gitmark.py lint --strict` чист. Артефакт: вывод lint.
