## Конкурс вариантов закрытия пробела всей картины (G7)

Оператор делегировал выбор: «проведи конкурс, оцени и выбери лучшее».
Пробел: чек-листы требуют всей картины (объём относительно тикета,
демо-путь, состояние runbook, межсрезовые дефекты), вход среза — только
его кусок. Критерии: полнота закрытия четырёх проверок; инвариант
(полный дифф не в промпте роли); фильтр-безопасность (bounded агрегат);
скоуп (без новых ролей); цена (дети/волны).

| вариант | закрывает | инвариант | фильтр-риск | скоуп | цена |
|---|---|---|---|---|---|
| A названный пробел | объём | ✓ | нет | мин | 0 |
| B синтезатор читает полный дифф | все 4 | ✗ | высокий (агрегат у родителя) | мин | 0 |
| C новая роль whole-picture | все 4 | ✗ + Рамки запрещают | высокий | новая роль | +1 |
| **D справка картины + seam-ребёнок** | **все 4** | **✓** | **нет** | **без новых ролей** | **+1** |
| E обзорный срез каждому | частично | ✓ | нет | дубль D | +N |

Выбран **D**:
1. Полнота арифметикой при фиксации плана: объединение файлов/хунков ==
   `git diff --name-only base..head`, расхождение — стоп (прецедент
   онто-дока, harnesses.md:138–140).
2. Справка картины — механически готовый bounded-артефакт (≤ кап):
   список файлов всем ролям; доказательство демо-пути (команда + вывод
   шага 2 ship) — reviewer-spec; выжимка интерфейсов (сигнатуры,
   импорты, зовы на границах срезов) — reviewer-code.
3. Seam-ребёнок reviewer-code на выжимке после срезов, один ребёнок,
   маршрут роли; выжимка названа в плане до спавна.
4. Runbook — целевое чтение continue.md по требованию (промпт bounded).

B/C отвергнуты: воссоздают агрегат, который юнит устраняет (полный дифф
в ревьюящем контексте), C нарушает Рамки. E доминируется D (каждой роли
только нужная часть + выделенная seam-проверка). Остаток D назван честно:
механическая выжимка может пропустить неочевидный шов — роль вправе
целевое чтение именованного артефакта.
