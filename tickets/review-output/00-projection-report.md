## Расхождения (разрешены триажем)

1. Пустота reviewer-kb / число активных ролей: KB = документы `docs/`
   (область reviewer-kb), корпус gitmark шире (включает skills/), но
   reviewer-kb ревьюит документы KB, не тексты бандлов. На инцидентном
   диффе docs/ нет → kb пуст; reviewer-code активен (тесты — код).
   Активных ролей 3 + названный пропуск. Пустая область операциональна:
   пересечение области с `git diff --name-only`.
2. Направление правки вердикта: убрать синтез, вердикт — выход роли
   (решение оператора 6); контракт «выход роли» и иглы «вердикт» не
   трогаются (минимально).
3. Оценка H4: «подтверждён повторами (n=3), не исключён полностью» —
   честная формулировка; детерминизм прохода ролей не доказывается.
4. Разброс приоритетов в группах — оценка тяжести, наивысший с
  注明来源; не конкурирующие находки.
